# The Last Terminus｜天空列车的最后一站

> 一列穿越不同尺度与空间法则的天空列车；一段由三个世界组成、从初次探索走向云海尽头的旅程。

本仓库保存项目世界观、体验方向、制作约定和 Agent 任务包。

## 项目当前定位

- **核心载体：** 一列连接不同世界的天空列车。
- **世界 01：** 书桌站《桌面以下》：微缩尺度、日常物件再利用、环境解谜。
- **世界 02：** 失重花园：空间方向、垂直探索、路线发现。
- **世界 03：** 云海尽头：宏大景观、观景、旅程收束，纯展示。
- **制作约束：** 一周冲刺；优先形成完整、独特、可玩的短旅程，不追求完整开放世界。
- **工具：** 抖音新版「造世界 AI 编辑器」，具体能力以当前版本实测为准。

## 生产原则

**方向明确，边界清楚，参考充分，结果开放，验证严格。**

Agent 应理解玩家体验和视觉目标，再根据实际工具能力提出方案、制作原型、比较结果。任务包定义的是目标、设计意图、边界和验收，不预先规定所有建模步骤、参数和内部实现。

总设计师负责总体设计、关键 Tripo 模型生成、方向决策和最终验收；A/B/C 对各自模块的生产、实测和交付负责。

## 本仓库不负责什么

- 不把《崩坏：星穹铁道》的角色、剧情、世界、视觉资产、UI 或音乐搬入项目。
- 不把《梦境邮局》作为本项目站点；该 Idea 已退出本项目。
- 不提前扩展第四个世界。
- 不把概念图等同于生产模型。
- 不假定造世界编辑器支持未实测的场景合并、脚本、载具或跨账号迁移能力。
