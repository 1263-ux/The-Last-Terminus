# 世界观圣经（World Bible）

状态：核心结构已确认；世界起源、列车真相和云隙本体仍开放。

## 1. 世界结构：多个彼此独立的世界

[PROPOSED] 整个作品由多个彼此独立、空间规律不同的世界构成。它们并不一定共享连续的地理空间，天空列车是玩家穿行其间的共同载体。

这些世界不是普通地图的不同生物群系。每个世界应该拥有：
- 独特的空间尺度或空间规律。
- 能够被玩家感知的环境逻辑。
- 自己的地标、建筑/自然形态和生活痕迹。
- 一个区别于其他世界的主要体验。

## 2. 世界之间的空间：云隙（暂定名）

[PROPOSED] “云隙”可作为世界与世界之间的过渡空间候选名称。它不是已经定稿的宇宙学设定。

当前可采用的视觉解释：
- 云海、雾层、远处浮岛和断续铁路。
- 列车行驶时，窗外可以短暂出现不同世界的轮廓。
- 世界切换不一定表现为物理上连续的长距离行驶，可以通过列车过场、隧道、雾幕或站台入口完成。

不要在本轮强行解释云隙的起源、边界或物理规律。先保证视觉和体验逻辑成立。

## 3. 天空列车的存在规则

[PROPOSED] 列车可以在不同世界的交界处停靠。每个站点是当地世界与铁路发生连接的位置。

当前只需要确立玩家可理解的表层规则：
1. 列车连接三个不同世界。
2. 玩家可以在指定站点下车。
3. 玩家可以探索站点，并在完成体验后继续旅程。
4. 列车内部作为共同过渡空间，保持视觉和交互一致。

开放问题：
- 列车是谁建造的？
- 列车为什么能够穿越世界？
- 铁路是实体轨道、空间路径，还是某种抽象连接？
- 为什么本次旅程停靠这三个世界？
- 最后一站为何是终点？

这些问题不应由 Agent 擅自补完。

## 4. 三个世界的共同逻辑

三个世界应当在体验层面形成递进，而不是强行套用同一套收集任务。

[PROPOSED] 当前主题递进：
- 书桌站：尺度——熟悉物件在微缩视角下变成完整世界。
- 失重花园：方向——玩家重新理解上下、路径和空间连接。
- 云海尽头：距离——玩家抵达远方，停下来回望旅程。

该主题结构是设计提案，最终需通过整体体验评审。

## 5. 世界叙事方式

优先使用环境叙事：
- 建筑的使用痕迹。
- 物件摆放和空间关系。
- 路线中断、修复或长期无人使用的痕迹。
- 灯光、声音和远景。
- 少量标识、车票、地图和短文本。

避免：
- 大量 NPC 长对话。
- 开场长篇世界观说明。
- 为解释谜题而写大段教程文本。
- 每个站点都重复“收集三件物品打开出口”。

## 6. 氛围基线

[CONFIRMED] 温馨、治愈、唯美为主要情绪方向；可以逐步加入神秘感与感动，但不以悲剧、恐怖或强行煽情为主。

## 7. 与《崩坏：星穹铁道》的关系

[CONFIRMED] 可以参考其核心结构：列车作为多世界旅行载体、不同世界拥有独立的视觉和文明气质、主线把不同世界串联起来。

禁止照搬：
- 星穹列车造型和具体设计。
- 星神、星核、命途、阵营等专有设定。
- 角色、剧情、世界地名和专有名词。
- UI、音乐、标志性场景和可识别资产。

我们的原创差异是：三个世界围绕不同尺度与空间法则展开，强调短篇旅行、探索、环境互动和视觉体验。
