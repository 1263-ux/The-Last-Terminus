# 天空列车设定（Train Design）

状态：列车作为共同载体已确认；列车名称、起源和完整内部结构均为提案或开放问题。

## 1. 设计定位

[CONFIRMED] 列车是连接三个世界的核心载体，不应只是一个传送菜单。

[PROPOSED] 列车同时承担三个功能：
1. **交通载体：** 让玩家感知从一个世界前往另一个世界。
2. **共同空间：** 为三个风格不同的世界提供统一的视觉和情绪锚点。
3. **旅程记忆容器：** 记录玩家访问过的世界，承载少量纪念物和路线信息。

## 2. 外观方向

[PROPOSED] 采用“古老、真实、略带神秘”的列车气质：
- 保留可信的机械结构和列车比例。
- 可采用木质车厢、黄铜仪表、旧式灯具和暖色窗光。
- 车身有长期旅行留下的磨损和修补痕迹。
- 避免过度科幻化，也避免直接复刻现实某一款著名蒸汽机车。
- 魔法感通过环境、窗外景象和少量异常细节表达，不依赖满屏粒子特效。

暂定名称“循界号”仅为命名候选，尚未确认。Agent 不得在正式 UI、模型铭牌或文案中固定使用，除非总设计确认。

## 3. 首版空间范围

[PROPOSED] 一节主要车厢 + 一个连接平台/车门区域即可。

### 3.1 观景区域
- 大窗户，能够看到云海或即将抵达的世界。
- 座椅、行李架、灯具等少量生活化细节。
- 主要作用是建立旅行感，不做复杂可操作家具。

### 3.2 旅程地图
- 展示三个站点及其顺序。
- 标记已到访、当前和终点。
- 视觉上像车厢中的实体路线图或地图装置。
- 不需要复杂地图编辑系统。

### 3.3 纪念物陈列
- 可展示书桌站的小地图/微缩纪念物。
- 可展示失重花园的种子或花朵意象。
- 最后一站可留下旅程记录或照片。
- 第一版可以采用静态陈列，不做复杂背包系统。

## 4. 列车与站点的连接方式

[TO-VERIFY] 需要实测造世界 AI 编辑器是否支持：
- 场景内列车/载具移动。
- 列车门触发与到站演出。
- 世界/地图之间的传送或场景切换。
- 进入不同世界后返回列车。
- 多个独立工程或场景的资源交接。

如果不能可靠实现真实移动列车，使用以下降级：
1. 列车静态停靠，玩家通过车门进入站点。
2. 使用短过场、镜头移动、雾幕或传送触发模拟行驶。
3. 使用统一的到站音效、汽笛和灯光变化建立连续感。

不要让真实列车物理成为项目阻塞项。

## 5. 列车的声音识别

[PROPOSED]
- 低频、克制的机械运行声。
- 远距离汽笛声。
- 车厢木材、金属和玻璃的细微环境声。
- 到站时使用统一的提示音/汽笛动机。
- 不要让列车持续噪声覆盖各世界的环境音乐。

## 6. 叙事线索

可在列车中放置少量线索：
- 一张不完整的线路图。
- 一只显示异常时间的旧钟。
- 一张没有目的地名称的车票。
- 车厢中与终点站相同的纹样。

这些都是[PROPOSED]氛围线索，不代表已决定列车的最终真相。首版只选择一至两个，避免堆砌神秘符号。
