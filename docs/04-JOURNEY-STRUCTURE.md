# 旅程叙事与体验结构

状态：三个世界的顺序与职责已确认；具体剧情线索和最终解释仍为提案。

## 1. 旅程总结构

1. **登车/启程：** 玩家进入天空列车，理解列车是连接不同世界的载体。
2. **第一站：书桌站《桌面以下》：** 玩家体验微观尺度和物件改造。
3. **第二站：失重花园：** 玩家体验空间方向和垂直路线发现。
4. **第三站：云海尽头：** 玩家抵达终点站，完成纯展示式的情绪收束。

本轮不增加第四个世界。

## 2. 开场提案

[PROPOSED] 可以从一座安静站台和一列亮着暖灯的古老列车开始。玩家登车后，窗外逐渐出现云海，车厢地图显示第一站。

不要求制作长篇开场动画。若编辑器演出能力有限，用列车静态场景、灯光、汽笛、镜头和短文字完成。

## 3. 每站体验结构

每个站点有独立的内部闭环，但不能重复同一种任务模板。

### 书桌站
观察日常物件 → 理解物件用途 → 完成一次物件改造/多解谜题 → 实际通过新路线 → 世界产生反馈。

### 失重花园
观察空间方向 → 发现不寻常的通行路线 → 利用平台/路径完成空间探索 → 抵达中央地标 → 获得视野奖励。

### 云海尽头
列车到站 → 下车 → 沿站台和地标漫游 → 抵达观景台 → 观看最终环境演出。

## 4. 列车的贯穿方式

[PROPOSED]
- 三个世界之间尽量出现同一节车厢或同一列车的视觉线索。
- 站点之间可以用短行驶过场、窗外景色变化、汽笛和灯光变化连接。
- 列车内部的地图/陈列可随旅程增加少量内容。
- 若编辑器无法实现无缝世界切换，采用独立场景入口与过场，不以无缝加载为目标。

## 5. 叙事密度

本轮采用“环境叙事为主、短文本为辅”：
- 不写大段角色对白。
- 不引入复杂乘客关系。
- 不解释列车所有秘密。
- 允许玩家从物件、站牌、路线图和建筑痕迹中自行推断。
- 最后一站不必揭露完整宇宙真相。

## 6. 旅程记录

[PROPOSED] 可用一张实体路线图或车厢陈列架记录到访经历。第一版只需视觉更新，不需要完整收藏数据库。

## 7. 节奏目标

建议整体体验控制在约 8–12 分钟作为初版目标：
- 启程与车厢：约 1 分钟。
- 书桌站：约 3–4 分钟。
- 失重花园：约 3–4 分钟。
- 云海尽头：约 1–2 分钟。

这是制作目标，不是已测得时长。必须通过实际试玩修订。
