# 参考作品与设计来源

本文件只定义“研究什么、如何转化”，不代表参考作品的内容属于本项目。

## 1. 《崩坏：星穹铁道》

参考方向：
- 以列车作为连接多个世界的叙事载体。
- 每个世界具有独立的视觉、文明和故事气质。
- 通过共同主线让多个世界成为一段连续旅程。
- 列车/共同空间为玩家提供熟悉感和归属感。

本项目转化：
- 以天空列车连接书桌站、失重花园和云海尽头。
- 三个世界拥有不同的空间法则和体验职责。
- 车厢是短小的共同空间，而非复杂经营系统。

禁止复制具体角色、场景、专有名词、剧情、标识、音乐、UI 和美术资产。

官方作品信息可从米哈游官方渠道和游戏内资料核验。设计研究应聚焦结构，不以二手同人设定作为依据。

## 2. Grounded

参考：微缩视角、普通物件成为巨大地标、环境分区和探索路线。

转化：书本成为峡谷，尺子成为桥，铅笔盒成为小镇边界，杯子成为港口。

不转化：生存压力、战斗和敌对生物循环。

## 3. Tiny Glade

参考：手工微缩建筑、模块组合、细节密度、舒适光照。

转化：书桌站的微缩建筑语言和列车车厢细节。

不转化：中世纪城堡主题和纯自由建造定位。

## 4. A Short Hike

参考：小规模地图的探索节奏、支路、捷径和好奇心奖励。

转化：两个可玩世界都要有清楚主路线与可选发现。

不转化：像素画风和登山主题。

## 5. The Last Campfire

参考：温柔的环境叙事、小场景谜题、克制的情绪表达。

转化：用环境、光线和少量物件讲述世界，不靠长对白。

## 6. 参考使用规则

- 参考图仅用于内部研究和设计分析。
- 不将游戏截图作为正式模型贴图或游戏内素材。
- 不复制可识别的角色、建筑、UI 或标志性场景。
- 每项参考都要写明“观察到什么—为何适用—如何转化为原创设计”。
- 如果参考与本仓库已确认决策冲突，以已确认决策为准。
