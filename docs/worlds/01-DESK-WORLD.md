# 世界 01：书桌站《桌面以下》

状态：核心玩法与玩家身份来自此前已确认的《桌面以下》设计；作为列车站点的空间连接方式仍需完善。

## 1. 世界定位

[CONFIRMED] 《桌面以下》保留为《天空列车的最后一站》的一个完整站点，不再作为本轮独立的完整开放世界项目推进。

主题：微观尺度、日常物件再利用、探索与创造。

一句话：玩家进入一张巨大书桌构成的微缩文明，利用观察和物件改造，探索原本互不相通的区域。

## 2. 玩家身份与情绪

[CONFIRMED]
- 玩家身份：独立探险者。
- 核心自由度：有限自由度，允许多种解法。
- 长期成长理念：自己的微缩基地和收藏。
- 整体情绪：温馨治愈为主，逐渐出现神秘与感动。

本轮不必完整实现原先设想的全部基地成长系统，但应保留其视觉/叙事痕迹，例如小型探险工作间、地图墙或收藏架。

## 3. 空间构成

[PROPOSED] 书桌站可以包含以下区域，但一周版本只选择其中最能支撑玩法和画面的部分：

- **铅笔盒小镇：** 站点入口、居民生活、微缩建筑和探险工作间。
- **书谷：** 巨大书本构成峡谷、高台和悬崖。
- **文具区域：** 铅笔、回形针、橡皮等日常物件形成地形和机关。
- **杯岸港口：** 陶瓷杯和杯柄构成港湾、环形道路与远景地标。

## 4. 核心玩法

[CONFIRMED] 有限自由度的物件互动与多解环境谜题。

物件能力候选：
| 物件 | 可能用途 |
|---|---|
| 尺子 | 跨越、支撑、滑行 |
| 书页 | 坡道、遮挡、平台 |
| 回形针 | 固定、连接、悬挂 |
| 橡皮 | 配重、支撑、阻挡 |
| 铅笔 | 滚动、支撑、轨道 |
| 橡皮筋 | 拉动、弹射 |
| 纸飞机/纸翼 | 短程滑翔 |

不要求首版实现所有组合。每个谜题建议一个主解法和一个替代解法；组合关系由锚点、能力标签和关卡白名单控制，不做任意物理沙盒。

## 5. 关卡闭环示例：尺子桥

1. 玩家抵达书谷，看到两本巨大书之间的断裂通道。
2. 场景让玩家注意到尺子和两个可用支点。
3. 玩家选择尺子，通过受约束的摆放/吸附方式搭桥。
4. 摆放成功后桥梁可通行。
5. 玩家亲自走过桥，而不是只看机关动画。
6. 对岸小镇出现可观察反馈，例如灯亮、居民开始使用道路或地图路线更新。
7. 玩家可以继续探索支路或返回列车。

此谜题是本世界玩法方向示例，不代表新版造世界编辑器已经具备所有所需交互能力。必须先做编辑器最小验证。

## 6. 本轮制作建议

- 只选一个主要可玩区域，优先书谷 + 尺子桥 + 铅笔盒小镇局部。
- 通过远景让玩家看到杯子港口或更远的书桌区域，不必全部可达。
- 复用已有《桌面以下》模型和参考资产，但必须在新版造世界 AI 编辑器中验证导入、材质、比例、碰撞和交互。
- 核心资产：主角、两本书、尺子、铅笔盒入口、台灯。
- 普通装饰可以复用，避免核心区域风格拼贴。
- 不要为了复刻原始完整设计而把一周时间全部投入这一站。

## 7. 列车连接

[PROPOSED] 列车可停靠在书谷边缘或铅笔盒小镇旁的微型站台。列车与书桌之间的尺度差异应成为视觉亮点：列车可以被设计成适应微缩世界的列车，也可以采用世界尺度异常的表现，但两者尚未选择。

这是一个重要待决策点：列车究竟随世界缩放，还是所有站点都能看见同一列车的巨大/异常尺度？不要擅自决定。
