# 世界 02：失重花园

状态：作为第二个可玩世界已确认；具体自然法则、居民文明和核心谜题为设计提案。

## 1. 世界定位

主题：空间方向、垂直探索、路线发现。

一句话：玩家来到一个由悬浮岛屿、倒悬温室、巨型花朵和空中根系组成的花园，必须重新理解道路和空间连接方式。

## 2. 视觉构成

[PROPOSED]
- 漂浮在云层之间的大小岛屿。
- 倒悬或倾斜的温室。
- 巨型花朵和悬挂根系。
- 连接不同高度的桥、藤蔓和平台。
- 局部水流或发光植物作为视觉焦点。
- 远景有一座明显的中央花园/温室地标。

整体气质：空灵、安静、奇妙；不能过度堆满发光粒子或高饱和颜色。

## 3. 世界法则候选

[PROPOSED] 不同浮岛具有不同的“方向感”或局部空间朝向。玩家看到的道路可能沿岛屿侧面、底部或上方延伸。

[TO-VERIFY] 新版造世界 AI 编辑器是否支持真正的重力方向变化、移动平台、触发器、固定视角或传送组件。

首版不依赖真实任意方向重力。优先用：
- 不同高度的平台。
- 倾斜/倒置的静态建筑。
- 遮挡与视角切换。
- 预设路线和短距离传送。
- 可验证的移动平台（若组件实测可用）。

## 4. 核心玩法提案

与书桌站的“物件改造”明确区分。失重花园不应再次让玩家收集零件搭桥。

建议核心体验为**空间路线发现**：
1. 玩家从花园入口看到一个无法直接抵达的中央温室。
2. 通过观察花朵、根系、平台和建筑的朝向，发现可走的路线。
3. 在不同高度的平台之间移动，找到被遮挡的连接点。
4. 通过一个轻量机关或移动平台完成路线切换。
5. 抵达中央温室/观景点，看到整个花园的上下层结构。

## 5. 关卡结构

建议只做一个连续的小区域：
- 入口浮岛：建立方向错位的第一印象。
- 根系长廊：展示垂直路径。
- 倒悬温室：本世界主要地标和目标。
- 高处观景点：完成路线后的视觉奖励。

可选支路：一处隐藏花朵或小型观景台。不要扩成多岛屿大型开放世界。

## 6. 玩家体验

- 进入后 5–10 秒内看见中央温室或主要目标。
- 玩家通过观察理解路线，不依赖持续箭头。
- 至少有一次明显的“原来这里也能走”的发现。
- 不制造眩晕、强制视角翻转或不必要的跳跃惩罚。
- 失败后能快速回到安全位置。

## 7. 文明与生命痕迹

[PROPOSED] 可用少量环境细节暗示这里曾有人照料花园，例如工具台、植物标记、浇水装置、温室灯光。首版不要求复杂 NPC 文明，也不需要长篇历史说明。

## 8. 验收

- 一眼看出与书桌站不同。
- 玩家能理解本世界独有的空间规则。
- 至少完成一次路线发现/空间机关体验。
- 中央温室或高处观景点形成明确奖励。
- 玩法可在新版造世界编辑器中稳定运行。
