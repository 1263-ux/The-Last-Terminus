# 世界 03：云海尽头（最后一站）

状态：作为第三个纯展示世界已确认；终点的世界观真相尚未确定。

## 1. 世界定位

主题：距离、抵达、回望。

一句话：列车抵达一座建在云海边缘的终点站，玩家下车探索站台，最终抵达观景位置，看到旅程经过的世界轮廓。

## 2. 体验职责

[CONFIRMED] 本世界为纯展示世界，不承担复杂玩法系统。

它不是空白的风景背景。玩家应当可以：
- 看见列车驶入或停靠。
- 从站台下车。
- 沿一条清晰路线自由漫游。
- 经过一个具有辨识度的建筑地标。
- 抵达高处或边缘观景台。
- 欣赏云海、远方浮岛和铁路尽头。
- 通过音乐、光照和镜头完成旅程收束。

## 3. 空间构成

[PROPOSED]
1. **终点站台：** 列车停靠的主要空间，具有明确的到站仪式感。
2. **中央钟楼/站厅：** 远距离可识别的垂直地标。钟楼是否采用，仍可评审。
3. **云海观景台：** 本世界主要探索终点，提供大尺度视野。
4. **铁路尽头：** 铁轨逐渐消失在云层或远方，强调“最后一站”。
5. **远方世界轮廓：** 可以隐约看到书桌站和失重花园的视觉符号，但不要做成硬贴图式拼接。

## 4. 视觉方向

[PROPOSED]
- 主色：暖金、奶白、暮色蓝。
- 材质：石材、金属、玻璃、柔和云雾。
- 构图：大尺度建筑与空旷云海形成对比。
- 光照：夕阳或日出方向的暖光，远景有清晰层次。
- 细节：站牌、旧时刻表、长椅、行李、灯具和轨道磨损。

避免过度堆砌高塔、悬浮岛和粒子效果。需要有一个主地标和一个真正能让玩家停下来的观景点。

## 5. 最终演出提案

[PROPOSED]
- 列车减速进入站台。
- 汽笛或制动声出现，环境音乐逐渐展开。
- 玩家走下车，沿站台向观景台移动。
- 到达观景点时，云雾打开或光线变化。
- 远方出现前两个世界的轮廓/灯光。
- 镜头缓慢拉远，列车留在画面中。

如果编辑器不支持复杂时间轴，使用预设镜头、触发器、静态场景变化或短过场降级。

## 6. 不做什么

- 不做复杂 NPC 任务。
- 不做收集三件物品开门。
- 不做战斗或最终 Boss。
- 不做大规模可交互建筑。
- 不用空旷地图冒充宏大感；必须通过地标、路线、前中远景和光照建立空间层次。

## 7. 验收

玩家能从列车自然进入站台，沿路线抵达观景点；终点画面能够让玩家回想起前两个世界，并感受到旅程完成。
