## 7. Editor Operation Plan｜编辑器操作计划

按可执行顺序写出：
1. 打开哪个项目/场景。
2. 进入哪个编辑器区域/面板。
3. 导入或创建什么。
4. 修改哪些参数/对象。
5. 如何保存和创建检查点。
6. 如何预览和验证。
7. 如何导出/交付。

仅写已验证的按钮、菜单和功能。未知操作标记 TO-VERIFY，先做技术探针。

## 11. Acceptance Criteria｜验收标准

每条必须可观察、可测试，使用 PASS / FAIL / NOT TESTED。

- [ ] 设计方向符合对应世界设计卡。
- [ ] 场景入口、主路线和出口清楚。
- [ ] 核心玩法/展示体验可实际运行。
- [ ] 模型、材质、碰撞和比例符合要求。
- [ ] 保存后重新打开状态正常。
- [ ] 无严重卡死、穿模、软锁或丢失引用。
- [ ] 资产来源和许可已登记。
- [ ] 远景、中景、近景截图已提供。
- [ ] 完整运行录屏已提供。
- [ ] 世界交付包可由集成人员重新打开。
