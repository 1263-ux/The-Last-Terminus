# DAY 02｜白盒、空间路线与世界接口

## 本阶段目标
把设计提案变成可观察、可走通的空间原型。今天先验证空间和路线，不追求最终美术。

## A｜列车与集成
- 制作紧凑列车 Hub 白盒，验证出生点、旅程信息、观察窗和下一站入口。
- 制作云海尽头白盒：列车停靠、主地标、观景路线和最终视野。
- 与 B/C 确认统一 Entry/Exit Anchor 和返回列车约定。
- 尽早用占位世界做一次入口/出口连接测试。

交付：Hub 和终点站白盒、路线/俯视图、玩家视角录屏、接口约定草案、连接探针。

## B｜书桌站
- 将书谷、尺子桥、铅笔盒小镇组织成一个连续可探索区域。
- 验证玩家尺度、目标可见性、主路线和可选路线。
- 让尺子桥在白盒中体现“可改变通路”的位置关系。
- 远景可以出现杯岸港口和台灯，但不扩成额外完整地图。

交付：可走通白盒、入口/目标/主路线/支路截图、玩家视角录屏、碰撞和尺度问题。

## C｜失重花园
- 将入口、不同高度层、根系/平台连接、温室目标和观景点组织成连续空间。
- 目标应从入口可见，路线线索应可观察。
- 验证三层之间能否安全通行，避免无意义跳跃和频繁坠落。
- 可以比较环形结构和线性探索结构，选择更适合编辑器与玩家视角的方案。

交付：白盒、空间拓扑/路线图、目标视线截图、连续录屏、平台和碰撞问题。

## 跨团队协作
- A 提供玩家尺度和接口草案；B/C 尽早反馈是否适合自己的空间。
- B/C 提交 Entry/Exit Anchor 的实际位置/朝向截图。
- A 不等完整世界，先用白盒和占位资产测试连接。
- 若项目迁移未解决，三个世界继续独立白盒，接口文档照常推进。

## Gate D2
通过条件：
- 玩家能理解入口、目标和主路线。
- 两个世界空间体验有明显区别。
- 核心区域可实际走通或能明确展示未通原因。
- A/B/C 的接口信息足以开始连接测试。

未通过：保留白盒，按问题修改；不进入精细模型生产。
