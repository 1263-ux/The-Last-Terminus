# DAY 07｜最终验收与交付

## 本阶段目标
形成可重新打开、可演示、可恢复、资产来源清楚的稳定作品版本。

## A｜列车与集成
- 冻结最终集成候选版本。
- 验证项目保存、关闭、重新打开。
- 检查三个世界的顺序、入口出口和完整旅程。
- 汇总稳定 Commit、恢复说明、资源依赖和发布限制。
- 输出完整旅程连续录屏。

## B｜书桌站
- 验证最终集成版本中的书谷、尺子桥、小镇、隐藏路线和核心玩法。
- 确认资产、材质、碰撞和交互状态保存后可恢复。
- 输出世界展示截图、完整玩法录屏、资产清单和已知问题。

## C｜失重花园
- 验证最终集成版本中的浮空空间、路线发现、温室和观景点。
- 确认平台/机关、碰撞和材质保存后可恢复。
- 输出世界展示截图、完整玩法录屏、资产清单和已知问题。

## 最终验收清单
- 项目可重新打开。
- 完整旅程可从头到尾体验。
- 两个可玩世界的核心玩法均成立且彼此不同。
- 云海尽头形成清晰的旅程收束。
- 无 P0 缺陷。
- 关键模型没有严重破损、材质丢失或错误比例。
- 音乐/音效实际试听通过，授权信息可追溯。
- Git 有稳定版本和恢复说明。
- 完整录屏、截图、资产清单、已知问题和复盘齐全。

## 最终交付
- 稳定 Git Commit。
- 可重新打开的原生项目/资产包及恢复说明。
- 三个世界展示截图。
- 完整旅程录屏。
- 两个玩法完整录屏。
- 资产与授权清单。
- 已知问题与降级项。
- 一页项目复盘：有效做法、失败尝试、剩余风险和可复用资产。

## Gate D7
总设计师进行最终验收。Agent 和成员只能提交证据与建议，不能自行把最终版本标记为已通过。
