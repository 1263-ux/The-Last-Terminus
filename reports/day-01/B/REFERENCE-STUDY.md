# 书桌站｜参考研究（Grounded / Tiny Glade / A Short Hike / The Last Campfire）

> 项目：《天空列车的最后一站》—「书桌站《桌面以下》」
> 文档性质：**分析性参考研究**，服务于「物件用途重构」这一核心玩法与 6 个空间模块。
> 版本：day-01 / B 线

---

## 0. 研究原则与边界

### 0.1 这份文档要解决什么问题

书桌站的核心不是"小"，而是**"小的时候，日常物件的功能被重新分配"**。所以本研究的筛选标准只有一条：

> 一个参考只有在**能指出"哪一面墙、哪一束光、哪一个尺寸关系"**时才算数。

因此本文对每款游戏只记录三类东西：

1. **可被复述的具体场景**（镜头里有什么、玩家被要求做什么、反馈是什么）；
2. **它解决的是哪个设计问题**（迷路？看不懂？不想探索？解不出来？）；
3. **它为什么不能被直接搬**（IP、语调、内容体量、技术代价）。

### 0.2 三条硬边界

| 边界 | 内容 | 后果 |
|---|---|---|
| **版权** | 本文引用的一切截图、GIF、宣传图版权归 Obsidian / Pounce Light / adamgryu / Hello Games 所有 | **不得作为素材入库**，不得贴进 build、不得二次分发；本文只做文字描述与分析 |
| **玩法** | 我们是**有限自由度的物件互动与多解环境谜题**（见世界文档 §4 `[CONFIRMED]`），不是生存、不是自由建造沙盒 | 任何"资源采集/自由建造/体力成长"的机制，只能取它的**空间与引导方法**，不取系统；收藏与基地作为**视觉痕迹**保留，不作为通行门槛 |
| **技术** | 我们不做 GPU 程序化砌砖、不做实时全局光照重写 | 参考 Tiny Glade 时，取"手工程度/触感"的判断标准，不取其管线 |

### 0.3 尺度基准（本文所有"近/中/远"以此为准）

为了让"近/中/远"可执行，先钉一个内部基准：

> **[PROPOSED] 本节全部数值为本文提出的设计提案，不是已确认设定。**
> 它只用来让下文"近/中/远"可执行、可争论；若与 `docs/worlds/01-DESK-WORLD.md` 后续确认的尺度冲突，以确认值重算本文所有镜头距离。
> 任何进入生产的比例，都必须先在造世界编辑器里实测一遍。

- 玩家身高 ≈ **15 mm**（约一粒米长）；
- 直尺长度 300 mm ⇒ **20 个玩家身高**，是可跨越的"桥"尺度；
- 一支铅笔 ≈ 175 mm ⇒ **约 12 个玩家身高**；
- 桌面到台灯灯罩 ≈ 250–350 mm ⇒ **远景级**。

据此定义镜头：

| 名称 | 距玩家 | 用途 |
|---|---|---|
| **near** | 0.3–1.5 身高（5–22 mm） | 材质可信度、可攀爬边缘、刻度/纹理作为落脚点 |
| **mid** | 3–8 身高（45–120 mm） | 单模块可读、解谜空间关系 |
| **far** | 20 身高以上（300 mm+） | 体量、目标可见性、氛围层 |

## 1. Grounded（Obsidian Entertainment，2020 EA / 2022 1.0）

### 1.1 具体观察

**观察 1｜"开局是雨林，抬头是后院"的双重读法**
开场玩家看到的是茂密雨林。采访明确指出：那些"树"其实是草叶；抬头才看到真正的树、房子，而且它们"高得不可能、远得不可能"。设计问题被解决的是——**在玩家学会任何操作之前，先用一次读图错误建立尺度感**，而不是靠 UI 说明。

**观察 2｜花园灯 = 夜里的灯塔（无人告知的功能性引导）**
主美 Sean Dunny 描述夜间玩法的处理：花园灯在雾里看起来"像一座灯塔"，团队明确把它当作夜间地标使用；他强调这类东西"不一定有直接玩法影响，但有间接影响——给你一条在夜里认路的方式"。这是**用光照做导航，而不是用箭头做导航**。

**观察 3｜飞盘卡在树篱里 → 变成 BOSS 平台**
美术总监 Kaz Aruga 讲飞盘的来源：办公室旁边有很高的树篱，飞盘总卡进去。游戏里飞盘就那样斜插在树篱中，**"它卡住的方式让它成为树篱 biome 的一块小平台"**，上面可以打一场蜘蛛 BOSS。物品的**卡住姿态**直接生成了可行走表面。

**观察 4｜棒球：完全没有玩法用途，纯粹是地标**
Sean Dunny 说棒球"不承担任何玩法用途"，它是**一片大空地旁边的地标**；"我倾向于在棒球旁建家，因为那里非常平坦开阔"。这句话同时暴露了两件事：地标要配"空旷"，玩家才会把地标当成坐标系原点。

**观察 5｜易拉罐：可以爬进去、在里面建基地**
易拉罐的玩法价值是**内部空间**——玩家能钻进去，在里面搭一个小基地，从而完全躲避蜘蛛等大型威胁。另外有个很能说明"考据深度"的细节：罐体最初做成了宽口罐，被同事指出"那个年代的易拉罐不是宽口的"，于是改模。（"罐内由顶部一个破孔投下一道单束光"这一具体打光细节，我**未能从检索到的来源中确认** `[TO-VERIFY]`。）

**观察 6｜盒装果汁的"制造史"决定形体**
团队为了做果汁盒去查"果汁盒怎么折、制造流程是什么"；美术 Sean Dunny 对比自己在《辐射：新维加斯》的工作，指出难点在于：**这个物体在尺度上是"一栋楼"，但材质必须是"一整片无缝连续材料"**——所以必须自研材质/着色器，"近距离要有细节，远距离还要读得出轮廓"。这是本项目最该抄的一条工程判断。

**观察 7｜果汁盒的品牌生态：Lemon Crime / Armed Raspberry / Juicestice Squad**
Brennecke 讲 Punch-O 这个虚构品牌属于一个叫 Mouthtown 的大公司，对标 Hi-C；美术 Mitch Loidolt 给包装上的角色编了完整故事线。他们同时承认**故意不说满**，因为"留白会催生玩家考据与讨论"。

> 来源：[Game Informer《Three Big Ways Grounded Nails Its Micro-Scaled Setup》](https://gameinformer.com/2020/04/28/three-big-ways-grounded-nails-its-micro-scaled-setup)、[Game Informer《Looking Into Grounded's Unnatural Wonders》](https://gameinformer.com/2020/05/05/looking-into-groundeds-unnatural-wonders)、[Inverse《Grounded developers reveal secret inspirations behind its incredible art》](https://www.inverse.com/gaming/grounded-release-concept-art-obsidian/amp)。

### 1.2 迁移方法

| Grounded 的做法 | 我们在书桌站怎么用 | 落到哪个模块 |
|---|---|---|
| 先用"读错"建立尺度，再解释 | **开场第一镜不给全身景**：镜头贴桌面掠过，玩家以为在看一片林间空地——其实是一叠纸的毛边。等玩家抬头（相机上摇）才看到台灯灯罩压在天上。尺度**靠误读被纠正**，不靠解说 | 书谷 / 台灯太阳 |
| 灯＝灯塔的夜间导航 | 铅笔盒小镇的**暖窗**不做成任务标记，只做"看得见但走不到"的方向感；暖光点必须**成串**（3–5 个一组），单个点无法构成方向 | 铅笔盒小镇 / 杯岸港口 |
| 卡住的姿态生成平台 | **所有"可站立表面"必须来自物件被卡住/压弯/折起的姿态**，而不是额外加一块平台模型。尺子桥的桥面来自尺子被两本书夹住后**微微下弯**的那一段 | 尺子桥 / 书谷 |
| 地标 + 空地 成对出现 | 书谷里每个巨型地标（一摞书、一个笔筒）旁边必须留一块**低矮、平坦、无遮挡**的"书页台地"，玩家才会把它当原点 | 书谷 |
| 内部空间即玩法空间 | 杯岸港口不做成纯背影：**杯口是弧形的悬崖**，杯壁内侧有一段釉面反光，暗示"里面是能进去的"；哪怕本期只做远景，也要留一条可见但不通的内壁通路 | 杯岸港口 |
| "一栋楼大小 + 一整片无缝材质" | 我们所有巨型物件都是**单一连续材质**（一根尺子、一整张纸）。因此**必须自研/定制材质**：近距离要看到木纤维与刻度压痕，远距离要能靠色块读出"这是木头"。这条是硬需求，不是加分项 | 全部模块 |
| 品牌考据式留白 | 桌面上的物件要有**使用史**（谁用过、怎么坏的）：橡皮被擦出一个斜面、尺子被刻过一个名字、便签被撕掉一半。但**不写说明书**，让玩家自己拼 | 全部模块 |

### 1.3 不能照搬

| 不要抄 | 为什么 |
|---|---|
| **90 年代美式品牌恶搞体系**（Punch-O / Jabby Cola / Yoked-Girth / Mouthtown 集团） | 那是 Obsidian 的自有 IP 与其**喜剧语调**。我们的语调是安静、夜、微光；照搬会变成"梗密度"驱动，破坏《最后一站》的情绪 |
| **让尺度"看着对"就随手 fudge 数值** | 他们的原话是"有时候我们会稍微改一下"。他们有 3A 美术团队凭手感调；我们人少，**必须有一张锁死的比例表**（物件真实尺寸→世界单位→可跨越性），否则解谜尺寸会崩 |
| **生存循环与昆虫生态模拟**（饥饿/疲劳 vital system、蚂蚁搬食物、狼蛛夜行） | 生态模拟是巨大的系统成本，且会把玩法从"重构用途"拽向"躲怪+采集"。我们只取**"夜间光照改变生物行为"的观感**（例如夜里只有飞蛾绕着台灯转），不取模拟 |
| **战斗/蜘蛛 BOSS/受击惩罚** | 我们有"危险感"的需求，但没有"失败惩罚"的位置。飞盘的**平台属性**可以搬，**BOSS 战**不搬 |
| **"可爱但致命"的反差萌** | 该反差是 Grounded 的品牌。我们的张力来自**被遗弃感**，不是被捕食感 |

## 2. Tiny Glade（Pounce Light，2024）

### 2.1 具体观察

**观察 1｜每个木板是"一小块自己"，不是一张贴图**
官方 Dev Diary 明确写了迭代过程：木墙的初版原型"只是一张贴图"，他们不满意；理由是——**"Tiny Glade 魅力的一大半，在于所有东西看起来都能摸到"**；最终每块木板都是独立的小件，由系统像砌砖一样逐块排布。木板"是耍大牌的"：细长、要绕开拱券、门窗、各种屋顶形状，得被切分。

**观察 2｜窗户用"到窗的符号距离"驱动墙皮破损**
窗户系统的实现：**"用一个 float 顶点属性编码到窗户的符号距离"**，据此在窗周围的抹灰上自动生成不规则破损，得到"被用过"的有机感。也就是——**材质的老化程度是被几何关系驱动的，不是手画的**。

**观察 3｜玩家把楼梯"用歪"了，于是他们把歪用做成了正式功能**
访谈里的两个原话场景：
- 有玩家把一堆灯笼的**木质部件**堆叠起来，做出了类似"木墙"的东西；
- 有人发现**把楼梯对齐之后看起来像城垛（machicolations）**，于是团队补了一个正式的城垛功能。

**观察 4｜"桥"根本不在计划里，玩家的需求逼出了整套 3D 抬高系统**
原话：桥一开始完全没规划，但太多人想造桥，于是他们做桥；这又演化成**一整套建筑抬高系统**，整个游戏从"贴着地形做的 2D"变成 3D。紧接着出现新问题：能抬高就要有支撑、要处理重叠。

**观察 5｜"被游戏注意到"的愉悦感，比画面更重要**
Anastasia Opara 把这个"最关键的要素"类比成 RPG 记住"你跟这个角色恋爱过、和那个角色是仇敌"——**游戏注意到你在做什么，并为你的意图现场生成结果**。Tom 的说法是：看着东西在眼前被搭起来，"就是实实在在地令人愉悦"。

**观察 6｜30 座以上的"格莱德"用起始建筑当教学**
每个 glade 有不同主题/季节，并放置**起始建筑**，作用是"展示一些你可能还没见过的构件"并定下该场景的调子。工具的验收标准被定为：**"它们能讲多少个故事"**。

**观察 7｜光照是有限额的，且雾是可控的**
- 团队自述：**"可能你注意到了，目前只有 32 盏灯真的照亮周围"**，正在做取消灯数上限的技术；
- 补丁日志里提到 UI 图标都吃到了 **screen-space global illumination** 的重度开销（甚至导致驱动超时）；
- 后期加入了**可控雾**：密度、高度、"贴地程度"三轴可调，可与时间流逝锁定或放开；冬季场景另有积雪控制。

### 2.2 迁移方法

| Tiny Glade 的做法 | 我们在书桌站怎么用 | 落到哪个模块 |
|---|---|---|
| "能摸到"＝构件级建模，不是贴图 | **所有可交互物件必须是"构件级"**：尺子上的刻度是压印凹槽（有体积）、书页是叠层（有厚度与毛边）、橡皮的擦痕是切面而不是贴图。**验收标准：near 镜头下，玩家能看出"这东西是怎么被造出来的"** | 全部模块 |
| 符号距离驱动老化 | 书谷的书页边缘要用**到"被翻过的地方"的距离**驱动泛黄与卷边；铅笔盒小镇的搪瓷要用**到磕碰点的距离**驱动掉漆。**老化必须有因果** | 书谷 / 铅笔盒小镇 |
| 玩家把工具用歪 → 官方收编 | **只借心态，不借系统。** 按 `[CONFIRMED]` 决策，尺子桥是**锚点 + 能力标签 + 关卡白名单**的吸附式摆放，不是自由物理。可借的是：**尺子不向玩家声明"我是桥"**，只声明"有长度、有重量、两端可卡"；白名单里的合法锚点应覆盖 2–3 种读法（跨、撑、滑） | 尺子桥（核心） |
| "桥"逼出抬高系统 | 我们要提前定义**支撑与重叠规则**：尺子架在两本书之间时，接触点是"可靠"还是"会滑"，必须有明确、可读的物理语义（视觉上就能看出会不会滑），否则玩家会把失败归因于游戏 | 尺子桥 |
| "游戏注意到你" | 交互反馈要做成**对象化的应答**：玩家把纸夹按在书页上，纸夹要"咬住"并给一个小回弹 + 音效；玩家抽出尺子时，书页要塌一下。**每一次重构都要有一次专属回应** | 尺子桥 / 布料坡面 |
| 起始建筑当教学 | 每个模块入口放一个**"半成品"范例**：不是教程关，而是"有人在这里这么干过"的现场（一把尺子已经架好了，但断在一半）。玩家看懂手法，再自己补完 | 全部模块 |
| 32 盏灯的预算 + 可控雾 | 我们的现实约束更好用：**台灯是唯一主光**，暖光点总数控制在 **≤12**（含铅笔盒窗户 6–8、书缝 2–3、杯岸 1）。远景靠**雾的三轴**（密度/高度/贴地）拉开层次，不靠加灯 | 台灯太阳 / 杯岸港口 |

### 2.3 不能照搬

| 不要抄 | 为什么 |
|---|---|
| **GPU 程序化砌砖/木板/屋顶的整套管线** | 那是两人十年的渲染积累（Bevy + Vulkan + 计算着色器 + 自研 GI）。我们照抄会直接死在技术里 |
| **"没有目标、没有失败"的玩具盒定位** | 官方把自己定位为"做立体模型（diorama）的玩具盒"，并明确**不人为制造事件**、玩家进入状态后不去打扰。我们的核心是**有明确终点的解谜**，需要节奏与关卡意图。只学"不打断"，不学"不设计" |
| **中世纪砖石/灰泥/茅草材质库** | 那是它的身份。我们的材质表是：**木、纸、金属、织物、陶瓷、石墨、橡胶**。不要借它们的色板 |
| **绵羊、城堡、旗帜等吉祥物系统** | 语调不同：他们是童话明亮，我们是夜、旧、安静。吉祥物会破坏我们的孤独感 |
| **"每块木板独立成件"的无节制细度** | 他们最终可以把砖数堆到百万级。我们的桌面上只有几十个物件，**细度预算应集中在玩家会贴近的 3–5 个物件上**，其余允许远景简化 |

## 3. A Short Hike（Adam Robinson-Yu，2019）

### 3.1 具体观察

以下细节来自作者本人在 GDC 的复盘演讲《Crafting A Tiny Open World: A Short Hike Postmortem》。

**观察 1｜主路线是一个"看起来过不去"的墙**
主线从一间小屋开始 → 进入小镇（在这里学会怎么玩、被介绍这个世界）→ **遇到一堵看起来无法通过的障碍**；玩家去收集金币和羽毛，获得攀爬能力，翻上去，才到山的左侧、更高的会合点。也就是说：**能力门被伪装成了地形门**。

**观察 2｜七根金色羽毛 = 体量的强制摊开**
到山顶需要 7 根金色羽毛。作者的解释很直接：这个设计让玩家**无法快速通关**，从而有更多时间去探索世界。这是"用一个数值门槛换取世界曝光量"的教科书式做法。

**观察 3｜玩家没按剧本走：跳海、绕岛、以及"从山背面溜过去"**
测试里出现的真实问题：很多玩家没有进入快节奏主线，而是**直接跳进海里**（可能只是想试试能不能游泳）；还有很多人**一直绕着岛走**；不少玩家**迷失在山脉背面**，于是**错过了重要的新手教学段**。而"更糟的是，最初版本的山的背面没多少东西可探索"。

**观察 4｜"加一个洞穴"救了新手教学**
解决方案不是加箭头，而是**在山背面加了一个洞穴**。作者的理由：走了很长一段路之后，**一个洞穴会激起好奇心**，玩家会穿过去，而穿过去就**直接被引导到新手教学段**。这是"用好奇心代替引导"的最干净案例。

**观察 5｜玩具铲子从 1 个变成 5 个**
原设计：开局放一把玩具铲子，留给"留意到它的玩家"；后来可以换成真铲子去挖东西。技术上完全可选，但错过会让人觉得错过了很多。结果是：**大量玩家因为各种原因避开了它**——有人看到山间的路就直接走过去了，有人看到悬崖就去爬，完全打乱了计划。最终方案：**在世界里放 5 把玩具铲子，都放在各区域的入口；只要拿起其中一把，其余四把自动消失**。于是"你没法忽略它"。

**观察 6｜门要做成"自然的门"**
作者明说他不用那种硬门（需要知识/经验才开的锁），而是**用"爬不上去的悬崖"当门**：这种门很自然，而且会让玩家觉得**或许还有别的解法**（集齐羽毛，或者拿到跳跃能力）。

**观察 7｜无声的条件式教学**
如果玩家还没有爬过悬崖，就会看到一个**引导他去爬山的信号**；如果他自己已经学会了，就**永远不会看到这些**。同理，攀爬（贴墙 + 按住键）不直观，于是做了"登山者俱乐部"：玩家收羽毛时要问他们怎么爬；**即使错过了任务，也可以路过时看别的角色怎么爬，从而学会**。

**观察 8｜最后一个区域：羽毛不回满，所以"到得了"≠"爬得上"**
终盘区域里，玩家的羽毛**不会自动恢复**：一旦冻僵，必须回到更暖的地方让羽毛恢复才能再来。于是玩家**不能靠攒的羽毛一路飞上山顶**，而要**计划在哪儿停留、攒够多少再冲**。作者还给山顶加了**一条清晰的路线**：玩家到这里能清楚看到怎么上去，却**没有足够的羽毛**，必须反复回来积累、做计划。他同时在测试中**增加了羽毛数量**——因为原本登顶太难会卡住进度。

**观察 9｜写作策略：短弹窗对话，像给好朋友发短信**
明确不做长过场，用简短的弹出对话，因为"写作本身很难"。

> 来源：[GDC Vault《Independent Games Summit: Crafting A Tiny Open World: 'A Short Hike' Postmortem》](https://www.gdcvault.com/play/1026613/Independent-Games-Summit-Crafting-A)、[GameLook 演讲听译全文（中文）](http://www.gamelook.com.cn/2020/10/400102/)、[A Short Hike 官网](https://ashorthike.com/)。

### 3.2 迁移方法

| A Short Hike 的做法 | 我们在书桌站怎么用 | 落到哪个模块 |
|---|---|---|
| 能力门伪装成地形门 | **尺子桥的"锁"不是锁，是缺口**：书谷两摞书之间有一个跨不过的缝，玩家第一反应是"找地方跳过去"，而正确答案是"把那把尺子推过去"。**永远不要出现"需要尺子"的提示** | 尺子桥 / 书谷 |
| 门槛数值强制摊开世界 | 我们需要一个**等价的"七根羽毛"**：不是收集品，而是**"三处必须亲眼看过的桌面事实"**（例如：看见尺子是弯的、看见杯里还有水、看见台灯会移动）。集齐才能解开最后一段 | 尺子桥 → 铅笔盒小镇 |
| 玩家会往"最不像路"的方向走 | **假设玩家第一件事是往反方向走**：书谷/布料坡面的背面必须**有内容**（一个被遗忘的笔帽、一页写了字的纸），否则玩家会像测试里那样"绕岛一圈然后什么都没看到" | 书谷 / 布料坡面 |
| 用洞穴（好奇心）替代箭头 | 每个模块的**入口都是一个"往里看能看到东西"的洞口**：书页之间的缝、笔袋的拉链口、杯子下方桌面上的一道光。**看得见内部，但看不全**，好奇心才会驱动 | 书谷 / 铅笔盒小镇 |
| 一件引导物放 5 份，拿一份消失 | 关键**教学物件**（例如第一把纸夹）应在**每个区域入口各放一个**，拿一个其余消失。**永远不要指望玩家注意到"唯一的那一个"** | 尺子桥 / 布料坡面 |
| 自然的门 = 爬不上去的悬崖 | 我们的"悬崖"是**光滑的桌面本身**（没有任何可攀附），以及**书页的切边**（能插进去、但爬不上）。玩家会自己推导"需要垫脚的东西" | 书谷 |
| 条件式教学（会了就不显示） | 引导必须**状态机化**：没做过 X 才提示 X；做过就彻底静默。**同一条提示不要在第二次出现** | 全部模块 |
| 终盘：到得了但爬不上 | 铅笔盒小镇必须是**"看得见暖窗，但进不去"**：玩家能走到外壳前，但门在另一侧/需要从内部推开。**终点要可见、可达、但先不可入** | 铅笔盒小镇 |
| 短句弹窗，不发长文 | 我们**不做长对白**。若需要文本，用**一行、像便签**的句子（这本身也符合"书桌"的物料） | 全部模块 |

### 3.3 不能照搬

| 不要抄 | 为什么 |
|---|---|
| **3D 像素化的画面方案**（低分辨率 RenderTexture + Point 采样放大、边缘检测描边、色带阴影） | 这套是作者为"技能树只有编程"做的取舍。我们的卖点是**材质可信度**（木纤维、纸毛边、釉面），像素化会直接摧毁它 |
| **羽毛/体力＝能力成长** | 一旦引入"收集 → 变强 → 解锁通行"，我们就会退化成轻量银河城。**我们的成长必须发生在"物件关系"上**：不是玩家变强，是桌子被重新组织 |
| **360° 自由开放世界** | 书桌是**有边界的立体模型（diorama）**。开放世界需要的内容密度会直接压垮我们。我们要"半开放"：主路 + 2 条支路 + 1 个隐藏 |
| **"没有真正解谜"的定位** | 作者在营销时明确说"节奏较慢、没有真正的解谜"。我们必须反着来：**解谜是主体**，节奏可以慢，但必须有明确的"我懂了"时刻 |
| **七个羽毛式的硬数值卡关** | 我们只有一次通关，硬数值门槛会让解谜玩家反感。用"必须理解的三件事"替代"必须收集的七件物" |

## 4. The Last Campfire（Hello Games，2020 / Steam 2021）

### 4.1 具体观察

**观察 1｜从"一幅壁画是倒的"开始教"世界是有规则的"**
序章：醒来，走过画着"余烬们朝圣之旅"的壁画，遇到不动的陌生人（已死）；拿走他的包，里面有一尊**金色小雕像**；**地板上的符号是倒着的**——玩家要在石门处**点击拖拽把它顺时针旋转**；随后石台升起、露出圆形凹槽，放雕像，解开一个滑块谜题。**第一个谜题同时是第一次世界观陈述**。

**观察 2｜每一个 Forlorn 都是"找到 + 解一组谜"的两层结构**
结构上：三大区域（森林 / 沼泽 / 洞穴），每区 7 个 Forlorn 和 1 处篝火；**区域顺序固定，但区域内部完全不线性**。每个 Forlorn 要**先找到**（往往靠解谜到达），找到之后**还要再解一组谜**才能取回它的 ember。谜题类型包括推箱子、符号配对、滚轮入坑、用古灯移动平台/梯子/蛇形平台、镜子导光、管道接通、风吹灭火焰等。

**观察 3｜"你脚下的东西也是你要操作的东西"**
官方向导给出的第一条基础规则就很有价值：**古灯能移动你正站着的东西**。具体例子：在「Path of Ruin」里，**要先站到滚轮上，再移动它**；在大坝那里，**移动配重来抬高你正站着的平台**。这制造了一种很特殊的紧张感——**操作与立足是同一件事**。

**观察 4｜"先想好回程，再去拿火"**
第二条基础规则：**在拿起火焰之前，先确认有路回来**。做法包括：把吹风的面转开、用方块挡住风口、改变高度、或躲到墙后。具体关卡「A Fragile Flame」要求你**用上一层的火焰重新点燃被吹灭的火把**，所以必须**先把燃烧的那捆移到右上方**。

**观察 5｜"方块的面"和"蛇的头尾"是同一个动作、不同的目的**
- 在「Kindling」里要把**燃烧面**朝上；在「Avoidance」里要把**吹风面**朝上；在「A Linear Road」里要把**地面面**朝上——动作几乎一样，但**目标完全不同**。
- 蛇形平台可以**从任意一端抓**；「Fractured Mind」里三条蛇分别是 3、5、6 格（含头尾）；「Healing Break」里升降机会改变"哪几节还连着"，所以要注意**你搬的是整条蛇还是其中一段**。

**观察 6｜"拆掉管道会降下你刚用过的楼梯"**
第四条基础规则：**永远检查光或水流向哪里**。镜子会在转角或旋转桥上改变朝向；**只有「Reflective Moment」里，接收器上的桥在被点亮后才会永久固定**。在「A Complex Machine」里，**拆掉一根管道会让你之前用过的楼梯下降**；解法是**先用上早期的管道，等下一层平台出现后再把挡路的直管取下、走过去、从另一侧装回去**。

**观察 7｜"可以只救 4 个就走"的宽容度 + 一键关掉谜题的辅助模式**
- 每个区域**救满 4 个就能点火离开**（全救是 7 个，全区 21 个）；
- 游戏有 **Adventure mode**，会**移除大部分谜题**（Normal mode 才有完整谜题）；
- 42 个日志箱是纯探索收集，与 21 个救援分开计数。

**观察 8｜结局把开场的壁画改掉了**
走到最后、点亮最后一处篝火后进到林间空地，**墙上的壁画现在画着两个在阳光下的余烬**——即开场那幅"朝圣"壁画被替换/改写了。世界观的和解是**通过修改一个玩家开局就看过的物件**完成的，不是靠台词。

**观察 9｜开发者自述的美学源头：Brian Froud 的童书**
Steve Burgess 说团队"成长于对民间故事的热爱，尤其是 Brian Froud 插画的童书"，并说"**那些书里每一页都像藏着一个只有你能看见的秘密**"。落到产品上就是一句硬要求：**"你撞见的每个区域都得有东西可发现——一个谜题、一个角色，或一个让你进入这个世界之谜的秘密。"** 他还说每个角色都带着**一种让他们感到无助的悲伤**，玩家通过"compassionate actions"帮他们面对。

### 4.2 迁移方法

| The Last Campfire 的做法 | 我们在书桌站怎么用 | 落到哪个模块 |
|---|---|---|
| 第一个谜题＝第一次世界观陈述 | **书桌站的第一个谜题必须是"桌子的规则"本身**：例如玩家发现"把纸立起来就能挡住光"，于是影子变了。规则第一次被使用，同时被理解 | 书谷（开场） |
| "脚下的也是要操作的" | 尺子桥的核心张力就用这条：**玩家站在尺子上时，尺子会因为重心移动而下弯/打滑**。玩家必须"先下来，再推"。这一条直接给我们一个非战斗的紧张感 | 尺子桥 |
| "先想好回程" | 布料坡面做成**单向坡**：布料的绒毛方向（nap）决定上坡滑不滑——**顺着毛上不去，逆着毛才抓得住**。玩家上一次滑下来之后才会去观察毛向 | 布料坡面 |
| 同一个动作、不同目的（面/头尾） | **同一个物件要能承担 2–3 种语义**：纸夹＝夹（固定）+ 钩（悬挂）+ 导电/配重。UI 上**不要写"纸夹：固定"**，让玩家用错一次再自己发现 | 尺子桥 / 书谷 |
| 拆管道会降楼梯（操作有代价） | **重构必须有代价**：把尺子从书堆里抽出来，书会塌——原先的通路消失。**不要给"免费的多用途"**，否则解谜消失 | 尺子桥 / 书谷 |
| 4/7 就放行 + 辅助模式 | 我们的**支路可以跳过**：主线必须能走通，两条支路（布料坡面 / 杯岸）是"理解加分项"。另设一个**"降低谜题难度"选项**（不是删谜题，是加大容错与提示密度） | 全部模块 |
| 结局改写开场壁画 | **终点要改写起点**：最后一刻让玩家回到书谷的同一处，看到**同一摞书**——但现在它们被自己推动过，位置变了。**用"同一个画面的变化"收尾**，不用 CG | 书谷 / 铅笔盒小镇 |
| 每区必有"谜题/角色/秘密"之一 | 每个模块必须至少有一个**"没什么用但很想看"的东西**：一根断掉的铅笔芯、一张写着字的便签、杯底的一圈咖啡渍。**这些是氛围的锚**，不是收集品 | 全部模块 |
| Brian Froud 式的"每页藏一个秘密" | 材质层面的执行：**书页里夹着东西（叶脉、压平的花、票根）**——只有当玩家把书翻开才能看到。**秘密藏在物件的结构里，不在物件的后面** | 书谷 / 铅笔盒小镇 |

### 4.3 不能照搬

| 不要抄 | 为什么 |
|---|---|
| **"悲伤的余烬/被拯救的迷失者"叙事装置** | Forlorn、鸟王、"虚假的希望"、最后的篝火，是 Hello Games 作者化的完整叙事。我们**没有"拯救他人"的位置**，照搬会变成廉价情感移植 |
| **古灯这一"万能钥匙"** | 古灯能移动方块、桥、梯子、蛇形平台——**它把一切互动都收束成一个工具**。这恰好与我们的"每个物件有专属用途"相反。**我们绝不能有一个通用操作器** |
| **21 个 Forlorn × 两层谜题的内容体量** | 那是 7–8 小时的内容量。我们只能做**一个主谜题链**，宁可深度高，不可数量多 |
| **"每个区域必须救 4 个"的配额式结构** | 配额会诱导我们做"填充谜题"。我们的结构应是**一条主链 + 两处可选理解** |
| **所有线索都靠"观察即解法"的温和难度** | 它的谜题几乎没有失败惩罚、也几乎不需要推理链。我们需要的难度略高：**要有"我看错了"的时刻**，而不是"我没看见" |
| **一段式旁白 + 钢琴弦乐的情绪配乐** | 我们的声音设计应是**物件的声音**（纸张、木头、金属、水），而不是叙事旁白。"有人在你耳边讲故事"会立刻改变游戏的孤独感 |

## 6. 结论：本项目应学什么、应避免什么

### 6.1 应学（按优先级）

1. **"卡住的姿态"就是地形**（Grounded）
   飞盘卡在树篱里就变成平台。**这条直接定义了我们的关卡制作流程：先摆物件，再看摆出来的空隙能不能走，最后才决定谜题。** 而不是"先画一条路，再找东西填"。

2. **巨型物件是"一栋楼大小的单一材质"，所以材质必须自研**（Grounded）
   一根尺子、一整张纸，都没有"拼缝"可以偷懒。近看要有纤维与压痕，远看要一眼是木头/纸。**这是美术的技术底线，不是风格选择。**

3. **"能摸到"＝构件级，不是贴图**（Tiny Glade）
   木板独立成件、窗户用符号距离驱动墙皮破损。我们照此执行：**刻度的凹槽、书页的毛边、橡皮的擦痕切面**，全部要有体积。

4. **玩家的"用歪"要能被系统接住**（Tiny Glade）
   玩家把楼梯当城垛，官方就做城垛。**注意降级**：受 `[CONFIRMED]` 的"锚点/白名单/不做物理沙盒"约束，我们取的是**心态**——尺子不声明"我是桥"，白名单里为跨/撑/滑各留一组合法锚点。**不是**给玩家自由物理。

5. **用好奇心代替箭头**（A Short Hike）
   山背面的洞穴把玩家"吸"进新手教学。**我们的每个入口都要是"看得见内部但看不全"的洞口。**

6. **关键引导物放多份，拿一份其余消失**（A Short Hike）
   1 把铲子会被忽略，5 把铲子无法忽略。**别把教学押在玩家的注意力上。**

7. **"操作对象＝立足对象"制造非战斗紧张感**（The Last Campfire）
   站在滚轮上再移动它。**我们的尺子会在玩家脚下下弯——这是本项目最便宜也最有效的张力来源。**

8. **重构必须有代价**（The Last Campfire 拆管道降楼梯）
   抽出尺子，书会塌，原路消失。**"免费的多用途"会直接杀掉解谜。**

9. **终点要改写起点**（The Last Campfire 壁画变化）
   最后一刻回到书谷同一摞书，位置被自己改过。**用同一画面的变化收尾，比任何 CG 都便宜且有效。**

10. **阴影色是情绪旋钮，不是物理结果**（A Short Hike 的蓝阴影＋推近白的 ramp）
    我们的夜景必须**偏蓝、不纯黑**；这是"温暖 vs 冷"能立住的唯一技术手段。

### 6.2 应避免

| 避免 | 原因 | 检查方式 |
|---|---|---|
| **通用操作器**（像古灯那样一个道具干所有事） | 会把"物件用途重构"降解成"找钥匙" | 每个交互必须能回答："为什么是这个物件，而不是别的？" |
| **收集→变强→解锁**的成长曲线 | 会退化成轻量银河城，玩家不再观察桌子。注意：世界文档 `[CONFIRMED]` 的"微缩基地与收藏"是**视觉痕迹**，不是通行货币 | 通行条件里不得出现"收集 N 个"；收藏只能出现在工作间/地图墙/收藏架 |
| **生存/生态模拟/战斗** | 系统成本极高，且与"安静的解谜"调性冲突 | 不出现血量、饥饿、怪物 AI |
| **90 年代品牌恶搞 / 吉祥物 / 可爱反差萌** | 破坏"夜、旧、孤独"的调性 | 任何物件不得有"好笑"的品牌名 |
| **把尺度数值凭手感 fudge** | 我们没有 3A 美术团队来兜底，解谜尺寸会崩 | 维护一张锁死的比例表，任何物件改动都要过表 |
| **照搬任何原作截图/美术** | 版权归原作者，且会被识别为抄袭 | 参考仅限文字分析；所有资产必须自绘/自制 |
| **"没有真正解谜"的温和定位** | 我们的核心卖点就是"我懂了"的那一刻 | 每个谜题必须有明确的顿悟点，且允许失败 |

### 6.3 一句话总结

> **Grounded 教我们"物件摆出来就有地形"，Tiny Glade 教我们"能摸到才算做出来"，A Short Hike 教我们"玩家不会按你想的方向走"，The Last Campfire 教我们"操作要有代价、收尾要回到起点"。**
> 四者合并成一句制作纪律：**先把桌子摆真，再让玩家去重新解释它。**
