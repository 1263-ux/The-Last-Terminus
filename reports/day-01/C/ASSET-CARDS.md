## 0. 共通约定

### 0.1 尺度基线

| 项 | 值 | 来源 |
|---|---|---|
| 单位 | 米 | 编辑器 |
| 上方向 | `+Y` | 编辑器 |
| 模型前向 | `+Z` | Three.js 作者规范 |
| 玩家眼平 | 1.60 m | `[待 A 确认]`，暂用此值 |

| 可站立面最小宽度 | ≥ 2.2 m | 白盒根系通道实测宽度 |
| 层高 | 根系层 0 / 温室层 9 / 花冠层 18 | 白盒 |

### 0.2 五条对所有资产生效的硬约束

1. **可走面必须能被玩家视觉识别为可走**。参考研究硬结论 1。装饰几何不得使用与可走面相同的材质语言。
   **补充（轮 20 血案）**：装饰几何**也不得放在可走路径中央**，哪怕它只是个 0.5 m 的小标记。
   白盒里的 `SpawnMarker`（0.5×0.5×0.5）被放在入口岛正中，把玩家**硬挡在走不出去**，
   而传送进同一位置又能站住——所以"能站"永远测不出它。**路线中央只放平贴地面的标记。**
2. **可走面不得有隐性起伏**。T-17 逐档实测：单级台阶上限 ∈ **[0.45, 0.50) m**，工程取值 **0.45 m**；白盒当前用 0.25–0.294 m，安全。注意圆弧顶面（如圆管根系）即使只有 0.4 m 也会挡人，因为它不是台阶而是连续斜面。
3. **坡度不是技术约束，但是体验约束**。T-18 实测 50° 仍可完整走完（45° 设计假设成立）；但角度越大水平推进越慢（50° 约为 10° 的 60%）。长距离通道建议 ≤ 20° 并做盲测计时。**"55° 站不住"这类说法已被证伪**，若要让挡边不可站，须做成 >70° 的硬挡边或不连续尖脊。
4. **透明玻璃可用，但细节靠几何**。T-19 验证 `alphaMode:BLEND` → `EnvLit_AlphaBlend_AI_Mat`，带贴图的半透面板确实能透出背景（截图 `43`）。原来的 `[TO-VERIFY]` 关闭。**但 `normalMap` / `ORM` 运行时会被丢弃**，所以玻璃的质感要靠玻璃分片、金属框架和真实厚度，不能靠法线/粗糙度贴图。
5. **贴图通道有取舍**。T-19：**albedo / emissive / 透明保留**，**normal / roughness / metalness 丢弃**。Tripo 生成时不要为法线或 ORM 贴图投入成本；表面层次靠真实几何，这也符合本任务包对植物结构可信度的要求。

### 0.3 材质结论（已更新，影响全部卡片）

Day 1 实测：GLB 内嵌材质在运行时被统一覆盖为 `EnvLit_AI_Mat`，颜色必须写 shader 的 `_BaseColor`（B-02 已解决，见 `PROBE-RESULTS.md` T-08）。

**贴图结论（轮 8 / T-08b）**：用编辑器 Three.js authoring 导出的 **KTX2 贴图 GLB 能正常导入，`_BaseTex` 采样有效**，红蓝棋盘与 UV 在运行时完整可见（截图 `42`）。所以**贴图细节可以依赖**，不必全部退回纯色。

但有三条约束要写进每张卡：

1. **格式**：必须是 KTX2（或先过编辑器 authoring 转换）。手写 `image/png` 的 GLB 在 runtime 阶段导入失败。
2. **分件仍然必要**：几何按材质合并成 `__optimized_merged_material_N`，同一资源内不同材质会被分开打包，但**颜色仍由 `_BaseColor` 决定**，不能靠 GLB 内嵌 color 做区分。
3. **未验证**：Tripo 的实际导出格式（需确认 KTX2）。`normal` / `ORM` 已确认被丢弃（T-19）；透明+贴图、albedo、emissive 已确认保留。

因此每张卡的「材质要求」仍写成**分件 + 语义材质槽**，但**贴图细节不再被排除**。

## GARDEN-001｜主巨型花朵

**优先级**：P0
**玩家用途**：花冠层的空间锚点 + **可站立平台**。玩家最终站在花瓣上完成观景。

### 观察距离

| 距离 | 用途 | 需要看清什么 |
|---|---|---|
| 40–55 m | 从入口浮岛看，作为远景地标 | 剪影必须独特，不能与温室混淆 |
| 12–20 m | 从空中平台链接近 | 花瓣层次、花心朝向 |
| 0–5 m | 玩家站在花瓣上 | 花瓣厚度、可站立区域边界 |

### 结构与轮廓

- 总高 **12–14 m**，花冠直径 **7–8 m**。要明显高于温室（温室高 ~5 m），形成"上重下轻"的倒挂感。
- 花瓣 **6–8 片**，分两层：外层大瓣向下垂（形成可站立面），内层小瓣向上卷。
- **可站立区**：外层的 2–3 片瓣，单瓣顶面宽度 ≥ 2.2 m，长度 ≥ 3 m，顶面坡度 ≤ 8°。
- 花心：直径 1.2 m 的凹陷，内部有发光结构（作为视觉焦点，不承载玩法）。
- 茎：直径 0.5 m，从花冠底部向下延伸 4–6 m，末端连接根系。

### 是否分件（必须分件，原因见 0.3）

| 分件 | 材质语义 | 备注 |
|---|---|---|
| `Petal_Walkable` | 不透明、粗糙、浅色 | **唯一的可走面语义**，必须与装饰花瓣材质不同 |
| `Petal_Decor` | 半透明、有渐变 | 内层装饰瓣 |
| `Flower_Core` | 自发光 | 视觉焦点 |
| `Stem` | 不透明、深色 | |
| `Root_Connector` | 同 GARDEN-003 的根系材质 | 保证与根系长廊材质一致 |

### 尺度参照

花瓣长度 ≈ 玩家身高 × 2（3.2 m）。玩家站上后，花冠边缘应在其腰部以下 —— 给"站在花上"的安全感。

### 参考图需求

- **1 张 45° 俯视**：看清花瓣层次与外层瓣的宽度（决定可站立性）
- **1 张仰视**：看清花心与茎的连接关系
- **1 张侧视**：看清整体剪影与倾斜方向

参考素材按 `VISUAL-REFERENCE-BOARD.md` §2 的 Ori 植物参考学习剪影方法。**不复制任何具体植物**。

### 碰撞与验收

- [ ] 可走花瓣有独立碰撞体，顶面平整，**起伏 ≤ 0.3 m**（实测阈值）
- [ ] 花瓣边缘有可见的边界（卷边/厚度），玩家不会误判边缘
- [ ] 站在花瓣上看，能同时看见「来路（根系通道）」和「下一个目标」（参考研究硬结论 3）
- [ ] 40 m 外剪影与温室不混淆
- [ ] 面数 ≤ 12k；贴图 ≤ 2048
- [ ] 导入后：不穿模、法线无翻转、透明件没有黑边

### Tripo 提示词草案

```
一株奇幻巨型花朵，高度约 13 米，花冠直径约 7.5 米。
外层 6 片宽大花瓣向下垂落，每片花瓣顶面平整宽阔可站立；内层 6 片小花瓣向上内卷。
花心中心有一个直径约 1.2 米的凹陷，内部有柔和自发光。
花冠底部由一根直径 0.5 米的主茎向下延伸，茎末端分成数根须根。
风格：风格化奇幻植物园，柔和薄荷绿与淡紫，哑光材质，花瓣有清晰厚度与卷边。
不要：写实苔藓、高饱和霓虹、大量粒子、卡通描边。
输出：单一花朵完整结构，花瓣分件，正面朝 +Z。
```

## GARDEN-002｜倒悬温室

**优先级**：P0（**本世界中央地标**）
**玩家用途**：目标物 + 中段可进入空间。是整个花园的视觉中心与路线转折点。

### 观察距离

| 距离 | 用途 | 需要看清什么 |
|---|---|---|
| 40–50 m | 从入口看，作为唯一目标 | **"它是倒的"必须在这一距离可读** |
| 15–25 m | 接近途中 | 玻璃与框架关系、入口位置 |
| 0–8 m | 进入 | 内部空间、可站立面、出口 |

### 结构与轮廓

- 主体：**六棱柱 + 半球顶**，直径 **7 m**，柱高 **5 m**，顶高 **3.5 m**。总高 8.5 m。
- **倒挂**：整体绕水平轴翻转 180°，半球顶朝下，平坦底面朝上。这是本世界"空间错位"的核心视觉。
- 框架：6 根立柱 + 2 道环箍 + 拱形肋。材质语义为深色金属。
- 玻璃：分片（不是一整块），每片之间有框架分隔。**这是性能与可读性的关键**——大面积单片透明会既吃性能又难看懂结构。
- 入口：底面上一个 **2.6 m 高、1.6 m 宽**的开口，朝向来路。

### 是否分件（必须分件）

| 分件 | 材质语义 | 备注 |
|---|---|---|
| `Glass_Panel` | 透明、低粗糙度 | **每片独立**，便于控制反射与性能 |
| `Frame_Structure` | 不透明金属 | 立柱、环箍、拱肋 |
| `Floor_Walkable` | 不透明、哑光 | 玩家在温室内部的站立面 |
| `Door_Frame` | 金属 | 入口边框，需要明显 |

### 尺度参照

温室直径 ≈ 玩家身高 × 4.4。玩家从入口看，温室应占屏高 **≥ 25%**（C-G2 验收项）。

### 关键设计约束（当天已经踩过的坑）

**"它是倒的"必须在 40 m 外可读**。Three.js 白盒里，倒挂主要靠半球顶朝下传达；但在实际玩家视角（自由第三人称、俯视 15°）下，这个信息**不够强**。

建议的强化手段（Day 2 白盒验证后再定稿）：
- 地面上**没有**对应的基础/地基 —— 建筑悬空，底下是玻璃顶
- 内部植物**向下生长**（从"地板"向上长的是普通温室；这里是从天花板向上长）
- 顶部的平坦面朝上，像一块可站的平台，但边缘是屋顶瓦片的背面

### 参考图需求

- **1 张俯视**：看清顶面（倒挂后的"地板"）的平坦度
- **1 张侧视**：看清倒挂姿态与框架节奏
- **1 张从下方看**：这是玩家在根系层抬头看到的视图，**最关键**
- 参考 `VISUAL-REFERENCE-BOARD.md` §4 的 Tiny Glade / Monument Valley（学习建筑轮廓可读性，不复制任何几何）

### 碰撞与验收

- [ ] 底面（倒挂后的顶面）可作为可站立面，**起伏 ≤ 0.3 m**
- [ ] 内部地板可站立，入口高度 ≥ 2.4 m（玩家通过）
- [ ] 玻璃为碰撞体（不能穿玻璃进出），但**不影响视线**
- [ ] 40 m 外能认出"这是一座倒着的玻璃建筑"
- [ ] 面数 ≤ 25k；玻璃贴图 ≤ 1024
- [ ] 导入后：透明件**无黑边**、玻璃后面能看到结构（不能变成不透明蓝块）

### Tripo 提示词草案

```
一座倒挂的玻璃温室，六棱柱主体直径 7 米、柱高 5 米，半球形穹顶高 3.5 米。
整体翻转 180 度：穹顶朝下，平坦的底面朝上。
深色金属框架：6 根立柱、2 道环形箍、若干拱形肋。玻璃分成多片，每片之间有框架分隔。
底面有一个 2.6 米高、1.6 米宽的开口作为入口，开口有金属边框。
风格：风格化奇幻建筑，玻璃通透不刺眼，金属哑光深青绿。
不要：写实反射、彩色玻璃、大面积极透明无框架、现代主义体块。
输出：完整建筑，玻璃与金属分件，入口朝 +Z。
```

## GARDEN-003｜根系长廊

**优先级**：P0（**本世界玩法核心**）
**玩家用途**：从入口浮岛通往温室下方的**唯一可走路径**。也是"原来这里也能走"这个发现的实际载体。

### 观察距离

| 距离 | 用途 | 需要看清什么 |
|---|---|---|
| 16–25 m | 从入口岛缘看（**关键距离**） | 根系的粗细差异——哪根能走、哪根不能 |
| 5–10 m | 走到根尖 | 可走面的宽度、接地斜坡 |
| 0–5 m | 走在上面 | 可行走面边界、脚下安全感 |

### 结构与轮廓

- 主根：**3–4 段**，总长 **14–18 m**，直径 **1.2–1.8 m**（顶面削平成可走面，宽度 ≥ 2.2 m）。
- 分叉：每段主根分出 **2–3 根支根**，直径 0.2–0.4 m，**必须明显细于主根**。
- 弯曲：主根有 1–2 处缓弯（曲率半径 ≥ 8 m），不出现急弯（急弯会让玩家看不清前方）。
- 接地：起点有 **≤ 0.3 m 的斜坡**接入岛面 —— 实测阈值，超过就上不去。
- 末端：接入温室下方平台。

### **这是最重要的一张卡：可走 vs 装饰**

当天白盒实测证明：**玩家会试图走任何看起来像路径的东西，而 0.4 m 的高差就能挡住他。**

因此根系必须做到**粗细差异可读**：

| | 可走主根 | 装饰支根 |
|---|---|---|
| 直径 | 1.2–1.8 m | 0.2–0.4 m |
| 顶面 | 削平，宽 ≥ 2.2 m | 圆柱，无平面 |
| 位置 | 玩家脚下高度 | **高于玩家头顶 3.2 m 以上** |
| 材质 | 与可走面同一语义 | 深色、粗糙、无高光 |
| 与玩家关系 | 可踩 | 明确触碰不到 |

**白盒已按此实现并走通。** 这条比例关系应作为资产验收的硬指标。

### 是否分件

| 分件 | 材质语义 |
|---|---|
| `Root_Main_Walkable` | 可走面语义（削平顶面） |
| `Root_Branch_Decor` | 装饰（细、暗） |
| `Moss_Patch` | 点缀，不得覆盖可走面边缘 |

### 尺度参照

主根直径 ≈ 玩家身高。玩家站在主根上，两侧各留约一人宽。

### 参考图需求

- **1 张从岛缘看的角度**：验证粗细差异是否可读（这是核心验收视角）
- **1 张近景**：可走面的削平质感

### 碰撞与验收

- [ ] 可走顶面连续，**无缺口、无 > 0.3 m 高差**
- [ ] 顶面宽度 ≥ 2.2 m（全程）
- [ ] 起步斜坡 ≤ 0.3 m
- [ ] 装饰支根**不进入玩家可达范围**（垂直距离 > 2.5 m）
- [ ] 面数 ≤ 15k
- [ ] 导入后实测：从岛缘一路走到温室下方平台，**中途无卡顿、无坠落**

### Tripo 提示词草案

```
一条由粗壮树根构成的自然通道，总长约 16 米，分 3 段缓弯相连。
主根直径 1.5 米，顶面被削成平坦宽阔的可行走面，宽度约 2.4 米，起点有缓坡接入地面。
每段主根侧面分出 2 到 3 根细支根，直径 0.3 米，向上方和侧面伸展，不构成可行走面。
根部表面有纵向纹理与苔藓点缀，但苔藓不覆盖顶面行走区域。
风格：风格化奇幻植物，哑光深棕，有生命力但不过度发光。
不要：藤蔓缠绕、发光脉络、写实树皮照片纹理、把支根做成和主根一样粗。
输出：连续根系，主根顶面平坦，正面朝 +Z。
```

## GARDEN-004｜浮空岛地形

**优先级**：P0
**玩家用途**：入口浮岛 + 温室下方平台 + 花冠观景台。是玩家实际站立的所有基础面。

### 观察距离

| 距离 | 用途 | 需看清 |
|---|---|---|
| 50–60 m | 远景，看整个花园轮廓 | 岛的厚度、倒锥岩层 |
| 10–20 m | 中景 | 岛缘的土壤断层、垂落植被 |
| 0–3 m | 站立 | 地面材质、边缘安全边界 |

### 结构与轮廓

- 顶面：**椭圆/圆形**，入口岛 r = 6 m，平台 r = 4 m，观景台 r = 4.5 m。
- 厚度：顶面草土层 0.8 m，下方**倒锥形岩层**，锥高 = 半径 × 1.3。
- 边缘：**土壤断层**（可见的分层）+ 垂落根系/藤蔓。
- **关键**：岛的底面必须有结构。参考 `VISUAL-REFERENCE-BOARD.md` §1 的观察——玩家从下方往上看时，岛底不能是一块平面。

### 是否分件

| 分件 | 材质语义 |
|---|---|
| `Terrain_Top_Walkable` | 草地，可走面语义 |
| `Soil_Layer` | 土壤断面 |
| `Rock_Underside` | 岩层 |
| `Hanging_Vegetation` | 垂落植物（装饰） |

### 尺度参照

入口岛直径 12 m ≈ 玩家身高 × 7.5。玩家站在中心能一眼看到岛的整个边界。

### 关于 AI 地形的说明

**AI 地形服务明确不支持浮空岛**（`BLOCKERS.md` B-03）。因此本卡有两条实现路径：

1. **推荐**：AI 地形只做顶面草地（连续地形），倒锥岩层由独立 Model 承担，两者在编辑器内组合。
2. 备选：整个浮岛用 Blender / Three.js 手工做。

- 1 张底面（岛底结构）

### 碰撞与验收

- [ ] 顶面平整，**起伏 ≤ 0.3 m**（玩家站立区域内）
- [ ] 边缘有可见但不可翻越的边界（崖壁），玩家不会意外掉下去
- [ ] 底面朝下也有几何（不能是单面片）
- [ ] 面数 ≤ 20k（远景岛 ≤ 3k）
- [ ] 导入后：站在岛上不穿模、不掉出

### Tripo 提示词草案

```
一座漂浮在空中的小型花园岛屿，整体直径 12 米。
顶面是平整的草地，边缘有清晰的土壤断层（能看到草皮、深色土壤、浅色岩层三层）。
岛体下方呈倒锥形收窄，裸露深色岩层，岩缝中有垂落的根系和藤蔓。
风格：风格化奇幻，柔和薄荷绿草地、暖棕土壤、冷灰蓝岩石。
不要：写实卫星照片纹理、尖锐破碎的岩石、发光水晶。
输出：完整浮岛，顶面平整可站立，正面朝 +Z。
```
