### 2.5 材质问题的解决证据（T-08）

**失败路径**（三次，保留记录）：

```
Three.js MeshStandardMaterial 颜色   → 运行时失效
appearanceData 组件 color            → 无变化，重新 attach 后组件丢失
mr.sharedMaterial.color              → 无变化（写错属性名）
```

**根因**：`Douyin/AI/PBR/EnvLit_AI` 的颜色属性是 `_BaseColor`，不是 `_Color`。

**A/B 对照**：

```
只改 _BaseColor（不动 _UseVertexColor）→ 颜色立即生效
```

**持久化验证**：关闭实例 → 新实例（`awc-ebd33eca-...`）→ 新 profile → `runtime start`

```
截图 13-colors-persisted-after-restart.png：三层配色自动恢复
走位复测 134.00 → 127.40，可走性未受影响
```
