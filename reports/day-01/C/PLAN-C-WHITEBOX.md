## 1. 为什么先做这件事

`SPATIAL-PROPOSALS.md` 推荐的是 **方案 C「反向生长」**（三方案对比 C 20 / B 19 / A 16）。但当时场景里的白盒实际上是**线性拓扑**——温室在入口**上方**。

也就是说：**被推荐的方案本身还没有被任何东西验证过。** 这是 Day 1 结束时最大的未闭合项。本轮把它补上。

## 2. 方案 C 的空间结构（已实现）

### 2.1 高度分层

| 层 | 高度 | 内容 |
|---|---|---|
| 花冠层 | y = 26 | 花冠观景台（终点，最高点） |
| 入口层 | y = 20 | 入口浮岛，玩家出生点 |
| 温室屋顶 | y = 16 | **可走面**（倒悬后原本的地面朝上） |
| 温室穹顶 | y = 8 | 尖端朝下 |
| 根系层 | y = 0 | 岛底岩锥与远景 |

**关键：目标在玩家下方，不是前方也不是上方。**

### 2.2 路线

```
出生点 (0, 20, -13)
  ↓ 朝 +Z 走
入口岛 (0, 20, -10)
  ↓ 正面是断桥（栏杆封住，过不去）
断桥断口 (0, 19.9, -3.6)   ← 直线路径在这里失效
  ↓ 转向 +X 侧
根系下坡 17 级 (x=4.2, y 20→16, z -4→10)   ← "原来这里也能走"
  ↓
温室屋顶 (0, 16, 8)   ← 玩家站在一栋倒着盖的房子房顶上
  ↓ 空中平台链 6 级 (y 17.2 → 26)
花冠观景台 (0, 26, 28.5)
```

### 2.3 断桥的作用（设计意图）

断桥不是装饰，是**「直线路径不成立」的实体证据**：

- 桥两侧有 0.9 m 栏杆，明确传达"这里过不去"
- 玩家在断口会本能地研究它（参考研究：允许 20–30 s）
- 真正的路在侧后方 +X 侧，需要转身才能看到

**这就是"原来这里也能走"的结构性来源**——不是藏了一条支路，而是玩家发现自己一直在错误的参照系里。

## 3. 实测结果

### 3.1 出生视角（截图 `25-planC-spawn-view.png`）

```
玩家 (120, 70.5, 102)，相机 forward (0.01, 0.95) 即正对 +Z
画面：正前方是断桥与栏杆，断桥下方是倒悬温室的屋顶（低于眼平线），
      更远处是花冠平台。目标可见，但"够不着"。
```

**达成的验收项**：
- ✅ 目标从入口可见（目标在下方，画面上部是天空，中部是温室屋顶轮廓）
- ✅ 直线路径受阻（断桥 + 栏杆）
- ✅ 不依赖 UI 箭头 / 文字提示

### 3.2 断桥处（截图 `27-planC-at-broken-bridge.png`）

玩家站在断口，画面里：
- 正前：两根栏杆夹着断掉的桥面
- 下方：倒悬温室的屋顶（深青蓝），一个明显的可站平面
- 上方：空中平台链与花冠台

**这是方案 C 最有说服力的一帧**：目标清晰可见、就在脚下，但当前路径过不去。

### 3.3 下坡行走（截图 `28-planC-on-descent.png`）

真实 `MoveContinuously`，从屋顶包围盒上方落下后沿 +Z 走：

```
start (116.50, 68.40, 117.30)
→ (116.50, 68.00, 118.40)
→ (116.50, 67.75, 119.60)
→ (116.50, 67.48, 120.70)
→ end   (116.50, 67.24, 121.60)
```

`y` **单调下降** 1.16 m，`z` 持续前进，全程踩在台阶上，无坠落。

### 3.4 抵达温室屋顶（截图 `29-planC-greenhouse-roof.png`）

```
end (117.60, 66.24, 126.00)
```

玩家站在温室屋顶边缘，脚下是带青色边缘的屋顶护栏，前方是空中平台链，头顶是花冠台。

## 4. 本轮修掉的两个真实缺陷

### 缺陷 1｜下坡台阶让人掉下去

第一版下坡用了 `x = 2.2 + sin(t*π)*1.2` 的外弧，想让它"看起来不像直桥"。结果：

- 台阶横向摆动，玩家走直线会从侧面走出去
- 实测：`y` 从 70 直接掉到 19.22，然后被世界边界清理弹回出生点

**修正**：改成**笔直沿 +Z、全程同宽 3.2 m、每级降 0.25 m**。重建后走通。

**这条与 T-05 是同一个教训的第二次出现**：可走面必须是可预测的，任何"为了好看"的几何变化都会变成玩家的坠落。

### 缺陷 2｜下坡起点与断桥重叠

第一版下坡放在 `x=0`，正好压在断桥的延长线上——那样断桥就不再是阻碍了，玩家可以顺着台阶直接下去。

**修正**：下坡移到 `x=4.2`（+X 侧），断桥保持在 `x=0`。现在断桥是真障碍，真路在侧后方。

## 5. 仍未解决 / 未验证

| 项 | 状态 | 说明 |
|---|---|---|
| **温室"倒着"的可读性** | ⚠️ 未验证 | 当前白盒里温室是一个玻璃筒 + 屋顶，从玩家视角看**更像一个正立的建筑**。参考研究 R-01 已预警："倒"必须靠结构而非错觉传达。这是 Day 2 的首要验证项 |
| 屋顶到空中平台链的衔接 | ⚠️ 未走通 | 屋顶 y=16，第一块平台 y=17.2，高差 1.2 m。按实测 0.3 m 阈值，**这一步现在上不去**，需要加中间台阶或矮化首块平台 |
| 花冠观景台的视野奖励 | 未验证 | 需要实际站上去看能不能同时认出"来路"和"下一个目标" |
| 坠落复位 | 未做 | 从屋顶掉下去目前直接落到 y≈19 被边界清理 |
| 分层配色在新结构的明度 | 部分验证 | 已按 R-07 压暗，但需要在美术阶段重测 |

### 5.1 屋顶→平台链接不上，必须优先修

这是**当前白盒的硬伤**。实测数据：

```
温室屋顶可走面 y = 16.0
第一块空中平台  y = 17.2   ← 高差 1.2 m
```

角色控制器实测上限约 **0.3 m**（T-05 反复验证过）。所以这条路线目前是**断的**——玩家能到屋顶，但上不去花冠层。

Day 2 第一件事就是修这个：在屋顶与第一块平台之间补 3–4 级 0.3 m 的台阶，或把首块平台降到 16.3。

## 6. 与设计文档的对齐情况

| `SPATIAL-PROPOSALS.md` 的设定 | 白盒实现 | 一致性 |
|---|---|---|
| 目标在玩家下方 | 温室屋顶 y=16，入口 y=20 | ✅ |
| 断桥阻断直线路径 | 断桥 + 两侧 0.9 m 栏杆 | ✅ |
| 根系是关键连接 | 17 级下坡台阶 + 圆管根系 | ✅ |
| 三层：花冠/温室/根系 | 26 / 16 / 0 | ✅ |
| 高处观景点是终点 | 花冠台 y=26，全图最高 | ✅ |
| 步长 ≤ 0.28 m | 下坡 0.25 m | ✅ |
| 不做真实重力反转 | 仅静态几何 | ✅ |
| 可走面宽度 ≥ 2.2 m | 下坡 3.2 m | ✅ |

**唯一明显偏差**：设计文档里"温室是 44 m 直径的玻璃碗"，白盒只有 8 m 直径。这是刻意的——白盒阶段先验证**空间关系**，体量留给美术阶段按真实镜头需求放大。
