## 一、核心发现（影响所有玩法设计）

### 1. 玩家是运动学刚体——物理碰撞不参与

**影响**：任何依赖"物体挡路"的设计都不成立。
**验证**：6 秒长距离行走测试，玩家穿过所有场景物体。
**替代方案**：Trigger + Teleport（已验证可靠）。

### 2. Lua `local` 变量不跨帧持久化

**影响**：门禁解锁状态、谜题进度等不能用 Lua 变量存储。
**验证**：6 轮测试（含干净场景单门禁）。
**替代方案**：节点位置存储（`GateStateMarker` z=0/1）——**已验证 PASS**。

### 3. `OnActorTriggerEnter` 在 Teleport 时不触发

**影响**：不能用触发器事件做解锁判断。
**替代方案**：`Update()` 轮询（每帧检查位置）。

### 4. 可见性定律（B 发现）

**公式**：`topY ≤ camY + d × 0.0787`，`d ≥ 5.2m`
**影响**：所有世界布局必须先过可见性检查。
**工具**：`tools/visibility_calc.py`

### 5. SCAD 管线（B 发现）

**区分**：`scene import <裸 GLB>` = 模型资产；**完整关卡**需 SCAD map 管线。
**管线**：`SCAD map → assembly → prefab → build → export → asset import → scene import`
