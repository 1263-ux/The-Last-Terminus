# B2｜渲染问题已解决：根因是"可见角度"，不是材质

分支：`feature/desk-world` · 编辑器 1.0.104
状态：**玩家视角渲染 PASS｜C4 场景可读｜闭环可验证**

---

## 0. 我之前的判断错在哪

过去两轮我把"玩家看不到物体"归因于材质、Shader、Layer、引擎限制——**全错**。

真相是一个**角度**问题，而且我算错过一次公式。

### 0.1 决定性证据

我把一个 2×2×2 方块放在**玩家身旁 1.8 m、胸口高度**，它出现了。
放在 6–20 m 正面、同样高度的方块不出现。

说明渲染完全正常，问题在**它是否落在视野角度内**。

### 0.2 正确公式

```
可见条件：
  角度 = atan2(topY − camY, z − camZ)·(180/π) + 俯角  ≤  半FOV
```

实测参数：

| 项 | 值 |
|---|---|
| `camY` | **79.587** |
| `camZ` | **85.3** |
| 俯角（pitch） | **18°（向下）** |
| 半 FOV | **22.5°**（FOV 45） |

相机向下看 18°，半 FOV 只有 22.5°，**地平线以上只剩 4.5° 余量**：

```
topY ≤ camY + (z − camZ) · tan(4.5°)  =  79.587 + d · 0.0787
```

### 0.3 我之前的公式错在哪

我写的是 `topY ≤ 80 + 0.1052·d`。

**错在把 `camY = 79.587` 当成了 `80`**，系数也用错了位置。
结果允许高度偏大约 30%，所有物体都刚好顶出画面上沿。

实测验证：

| 对象 | 距离 | 角度 | 结果 |
|---|---|---|---|
| 玩家身旁方块 | 4.3 m | **+9.1°** | ✅ 可见 |
| 书顶（旧） | 10.7 m | **+23.7°** | ❌ 出画（>22.5） |
| 门顶（旧） | 17.7 m | **+23.8°** | ❌ 出画（>22.5） |

## 2. 排除的其他假设（保留记录）

| # | 假设 | 结论 |
|---|---|---|
| 1 | 材质 alpha=0 / 用错 shader 属性 | **确有此 bug**（Standard 用 `_Color` 我设了 `_BaseColor`），已修，不是主因 |
| 2 | 必须用 URP/Lit | 试过，不是主因（Standard 也能渲染，只是 alpha 问题） |
| 3 | cullingMask 剔除 | 掩码含全部相关层，排除 |
| 4 | 引擎只渲染自家 shader | 排除（URP/Lit 可渲染） |
| 5 | 物体不在运行时 | 排除（层级里都在） |
| 6 | **物体顶出画面上沿** | ✅ **真正的根因** |

**教训：** 我把"看起来什么都没有"当成了"没渲染"。物体一直在渲染，只是**在我视野上方约 1°**。
