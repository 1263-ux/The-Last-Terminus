# B｜Day 3 最终结论：引擎渲染路径分裂

分支：`feature/desk-world` · 编辑器 1.0.104
状态：**机制 PASS｜玩家视角渲染 FAIL｜定向相机渲染 PASS**

## 0. 决定性观察

同一场景、同一时刻、同一批物体，**两条渲染路径给出相反结果**：

| 渲染路径 | 结果 | 证据 |
|---|---|---|
| **节点定向截图**（`screenshot --object`） | ✅ **全部清晰可见**，材质正确 | `evidence/day-03/11-glb-render-confirmed.jpg` |
| **玩家第三人称视角** | ❌ **只看到地面与阴影**，物体不可见 | `evidence/day-03/12-playerview-no-geometry.jpg` |

同时，引擎自己的可见性标记说物体是可见的：

```
C4_ERASER  y=80.10 z=91.5  vis=true  a=1.00
C4_BOOK_L  y=80.22 z=96.0  vis=true  a=1.00
C4_GATE    y=80.55 z=103.0 vis=true  a=1.00
C4_VILLAGE y=80.70 z=109.0 vis=true  a=1.00
（13 个中 10 个 vis=true）
```

**结论：物体被正确创建、正确着色、被引擎判定为可见，但玩家相机不绘制它们。**

## 1. 我为此排除过的 8 种解释

| # | 假设 | 方法 | 结果 |
|---|---|---|---|
| 1 | 相机 cullingMask 剔除 | 读 `cullingMask=-612353`，解出 layer 0/2/5/8/9/10 全开 | ❌ 排除 |
| 2 | 材质 alpha=0 | `_BaseColor=(0,0,0,0)` → 我的 bug（Standard 用 `_Color`） | ✅ 修好，`a=1.00` |
| 3 | 用错 shader 属性 | 同时设 `_Color`/`_BaseColor` + `_Mode=0` + `_ZWrite=1` | ✅ 已修 |
| 4 | 物体在相机背后 | `dotForward=-22.39` | ✅ 修正取景 |
| 5 | 不在视锥内 | 精确置于视线轴 8 m 处 | ❌ 仍不可见 |
| 6 | 尺寸过大出画 | 按 `h ≤ 0.1052·d` 预算重做全部尺寸 | ✅ 全部合规，仍不可见 |
| 7 | GLB 特有 | 导入 11 个 GLB 对照 | ❌ GLB 同样（在玩家视角）不可见 |
| 8 | 运行时未加载 | 层级遍历确认 11 个 GLB 节点存在 | ❌ 排除 |

**第 6 条最说明问题**：我严格按实测的可见带预算（26 m 处最高 2.32 m）把 8 m 墙压到 1.1 m，`vis=true`、`a=1.00`、尺寸合规，玩家视角仍然什么都没有。

## 2. 对玩法的影响（比渲染问题更严重）

### 2.1 碰撞：物体挡不住玩家（已确认）

```
Player_1: layer 8 (Actor)
Rigidbody.isKinematic = true
Rigidbody.useGravity  = false
Rigidbody.velocity    = (0,0,0)   ← 行走 30+ m 期间恒为 0
```

位移由 `NetworkActor` 脚本写 `transform`，求解器不参与 → **网格碰撞体不可能阻挡**。

场景层级 105 个节点里**没有地形对象**，但玩家稳定落地 → 地面来自引擎内部服务。

### 2.2 触发器的脚本列表为空

```
U3dObjectTrigger 可创建、可挂载
暴露 OnTriggerEnter / OnTriggerExit / OnTriggerPortal
但 _douyinScriptList = nil
```

→ 纯 CLI 搭的触发器**不会触发**，需要工程侧脚本注册。

### 2.3 依然可行的部分

| 能力 | 状态 |
|---|---|
| 读玩家位置 | ✅ |
| 写玩家位置 | ✅（但被控制器每帧覆盖） |
| 状态切换 `SetActive` | ✅ 立即生效 |
| 门禁规则判定 | ✅ `ruleFires: true → false` |
| 读相机参数 | ✅ |
| 写相机参数 | ❌ 被控制器覆写 |

**逻辑层完全可用，只是玩家看不见。**

## 3. 这对 B 线意味着什么

**书桌站的核心体验是「看见 → 观察 → 操作 → 通路改变 → 走过去」。**

五个环节里：
- 看见 ❌（玩家视角无渲染）
- 观察 ❌（同上）
- 操作 ⚠️（状态切换可用，但无触发绑定）
- 通路改变 ✅（逻辑成立）
- 走过去 ✅（可走）

**前两环断了，后面三环就失去意义。** 所以这不是"锦上添花的渲染问题"，而是**核心体验不成立**。
