# C｜盲测记录（Day 4 / Issue #23 P0-4）

> 结论：**NOT TESTED**（本轮无可用的非设计者玩家）

## 现状

- 设计总监要求：至少 **1–2 名未参与设计的玩家**，无口头路线提示，记录发现根系时间、错误转向、坠落、求助、完成时间和理解情况。
- 当前执行环境为 Agent 自动化会话，**没有任何真人玩家可调度**；无法把 Agent dry run 冒充真人盲测（Day 3 §5 已明确此红线）。

## 已做的替代验证（明确不等价）

| 项 | 做法 | 结论 |
|---|---|---|
| 路线可行性 | Agent 连续键盘输入实走（入口→根系→屋顶→台阶→花冠前平台） | 见 `CLEAN-SCENE-RETEST.md` §3：主体 PASS，花冠入口 FAIL |
| 45 s 提示 | 真实等待 + Lua 读数 | PASS（只触发 1 次/45 s） |
| 观景台可站 | Teleport 落定 `(120,76.01,135)` + 默认视角截图 | 台面存在；默认视角不见倒悬温室 |
| 坠落恢复 | 云垫触发 → 复位 `(120,70,107)`（重启前后各一次） | PASS |

## 需要真人完成的项

1. 默认到达视角：是否看见"下一个目标"；Look-back 3 秒内能否认出来路（禁止脚本转镜头）。
2. 从入口岛出发，无提示情况下能否自己发现"根系是路"（记录时间、错误转向、坠落次数）。
3. 花冠台入口（0.56 m 台沿/北槽）在真人操作下是"跳过去"还是"卡住"。
4. 走完路线后的主观理解：是否知道温室是倒悬的、下一步去哪。

## 安排

- 若无真人，维持 **NOT TESTED**，不阻塞清洁场景/接口交付（按设计总监 16:00 指示）。
- 有真人后按上述 4 项记录，回填本文件并更新 Gate 表。

## 盲测执行卡（给施测人，照抄即可）

**准备**：实例正常启动 → 新 runtime → 玩家出生（若出生点仍在地形顶，先按 `GUI-OPERATOR-CHECKLIST.md` 修，或临时传送到入口岛并在记录里注明）。

**收尾访谈（5 问）**
1. 你觉得这个花园最显眼的东西是什么？
2. 你是怎么找到往上的路的？
3. 温室为什么是倒的？你怎么看出来的？
4. 站到最高处时，你看到下一步该去哪了吗？
5. 有哪里让你不知道往哪走，或者差点掉下去？

**判定**：两名未参与设计者各自完成一次；两次都出现"发现根系 ≤ 60 s + 无口头提示完成路线"才判 C-06 PASS；否则记录偏差原因。
