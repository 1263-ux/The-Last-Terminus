# BelowTheDesk｜造世界编辑器资产交接包 v1.0

本包由用户上传的《BelowTheDesk 精简档案（2026-11-20）》整理而来，供《天空列车的最后一站》书桌站《桌面以下》使用。

## 包含内容
- 7 个精选 GLB：尺子桥、小镇街区、单体店铺、台灯、桌面底板、杯岸港口、Case 3 组合参考。
- 2 张原始视觉参考板。
- 原始 GDD、交互与谜题手册、世界地图、Art Bible、素材管线、音乐候选、垂直切片规格和决策记录。
- 对应资产的来源、建模报告、独立评审（若原档案存在）及校验信息。

## 重要边界
1. 本包不是新版造世界 AI 编辑器的原生工程，也不是可直接运行的 WPRE。
2. Blender 的独立评审状态不等于目标编辑器导入通过。B 必须在自己的造世界工程中逐项验证。
3. GLB 轴向、原点、比例、X 镜像、材质和嵌入贴图都要在目标编辑器运行时复测。
4. 原始资产不可覆盖；需要修复时复制为适配版本并保留原始文件。
5. 主角最终 GLB/动画不在本包中。第一版继续使用编辑器可用角色或现有角色占位，不得假称已交付定制主角。
6. 音乐清单是候选和许可初筛，不等于已人工试听或正式采用。

## 建议导入顺序
1. town-row-v02.glb（无贴图，验证多 mesh 层级与尺寸）
2. shopfront-v02.glb（无贴图，验证单体模块）
3. desk-lamp-v01.glb（无贴图，验证模型和摆位）
4. ruler-bridge-full-v01.glb（核心资产，重点检查嵌入 PNG 刻度）
5. cup-harbor-v03.glb（可选远景，非 P0）
6. ground-paper-v01.glb（底板/组合参考，不代表碰撞面）
7. case3-assembly-reference-v02.glb（仅作构图与导入行为参考，不直接作为最终关卡）

## 目标玩法适配
原设计中的整理模式、尺子吸附、预览、确认和实际过桥必须保留其体验意图；但新版造世界编辑器当前不能依赖普通 Collider 阻挡运动学玩家。应采用经实测的 Trigger/Lua 状态门禁与显式交互降级，不得假装实现了物理墙或任意物理摆放。
