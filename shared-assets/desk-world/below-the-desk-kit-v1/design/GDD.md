# 《桌面以下》游戏设计总纲 GDD v0.2

## 1. 产品定位

第三人称微缩探索冒险 / 环境解谜 / 轻量建造 / 收藏与基地成长。

**一句话：**
在一张巨大书桌构成的微缩世界里，玩家作为独立探险者探索日常物件构成的地形，利用有限物件摆放与组合开辟道路、解决谜题、帮助居民，并建立自己的探险基地。

### 四个体验支柱

1.  **尺度奇观：** 熟悉的桌面物品成为山脉、桥梁、港口和建筑。
2.  **创造性解谜：**
    一个目标通常有一个主解法和一个替代解法，少数区域提供进阶捷径。
3.  **世界回应：** 玩家修复的道路和设施会持续留在世界中，居民逐渐使用。
4.  **探索归属：** 玩家拥有工作间、地图墙、收藏和旅程记录。

### 非目标

不是生存游戏、战斗
RPG、自由物理沙盒、重度资源经营或纯收集游戏。不做饥饿、口渴、装备耐久、强制刷材料。

## 2. 玩家身份

玩家是一名独立探险者和地图绘制者，不是被预言选中的救世主。玩家来到铅笔盒小镇，发现旧地图残缺，决定重新探索桌面、记录路线、帮助居民重新连接区域。

主角识别元素：围巾、探险背包、小灯、靴子。主角动作要有微缩尺度的重量感。第一版只做移动、奔跑、跳跃、待机观察、交互、拖动物件等必要动画。

## 3. 世界观

桌面上存在一个独立微缩文明。居民把书本视作山脉，把铅笔盒视作小镇，把尺子视作道路，把杯子视作港湾。对居民而言，这些是自然存在的地理与建筑。

世界中偶尔会发生桌面主人造成的环境事件：翻书、放下铅笔、开关台灯。事件要有预兆，不随机伤害玩家，也不能破坏已完成谜题。

### 隐藏叙事：旧地图的主人

玩家逐渐发现儿童涂鸦、旧地图、纸飞机、便签和手写路线，暗示曾有一个孩子在这张桌面上创造和探索过这个世界，后来长大离开。不要强行煽情；通过环境叙事和收藏物逐步揭示，情绪落点是"曾经被认真想象过的地方，依然保留着温度"。

## 4. 核心循环

### 微循环

观察障碍 → 识别可用物件 → 推断用途 → 选择主/替代解法 → 摆放组合 →
实际通过 → 获得反馈。

### 区域循环

探索主路线和支路 → 完成关键谜题 → 帮助居民/发现秘密 → 解锁路线或物件知识
→ 区域状态变化 → 地图更新。

### 长循环

探索新区域 → 获得纪念品/工具知识/地图信息 → 带回基地 →
解锁展示或轻量功能 → 形成新探索可能。

## 5. 主要系统

-   **探索模式：** 第三人称移动、观察、跳跃、交互、触发机关。
-   **整理模式：**
    在指定改造区域进入俯视/斜俯视，选择物件、拖到合法锚点、预览、确认、撤销或重置。
-   **物件系统：**
    尺子（跨越/支撑）、书页（坡道/遮挡）、回形针（固定/连接）、橡皮（配重/支撑）；橡皮筋、铅笔、纸翼留待后续验证。
-   **基地：**
    铅笔盒小镇附近废弃隔间改成探险工作间。首版只做地图墙、收藏架、探险桌。
-   **收藏日志：**
    地图碎片、旧物记忆、区域纪念品、物件知识。必须来自探索发现，不靠重复刷取。

## 6. 章节方向

1.  《一张尚未完成的地图》：认识小镇、修复尺子桥、建立基地、进入书谷。
2.  《地图之外的世界》：深入书谷与文具荒野，学习物件组合，发现旧地图线索。
3.  《灯火抵达的地方》：抵达杯岸港口，修复区域连接，举办灯会，揭示旧地图主人的记忆。

## 7. 时长目标

首个垂直切片 5--8 分钟；首章完整体验目标 20--30 分钟主线，额外 10--30
分钟探索。时长必须由试玩测量，不得用重复收集填充。

## 8. 成功标准

玩家理解目标、能发现尺子与支点、独立完成搭桥、失败可恢复、世界有可见反馈、地图/日志更新、愿意继续探索。核心资产需通过远/中/近景和不同光照验收。
