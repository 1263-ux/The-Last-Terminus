# 世界地图与关卡设计方案 v0.2

## 1. 世界结构

一张连续桌面世界，不是四张独立关卡。采用"中心安全区 + 多条可回访路线 +
远景地标"。未解锁区域先可见，不必立即可达。

首版范围：书谷入口、尺子桥、铅笔盒小镇入口局部。文具荒野与杯岸港口只做远景预示。

## 2. 区域关系示意

``` text
                  [桌面远景 / 台灯]
                         |
             [文具荒野 - 后续开放]
                         |
[铅笔盒小镇] -- [书谷入口] -- [尺子桥] -- [书页高台]
      |                                  |
 [探险工作间]                       [杯岸港口 - 远景]
      |
 [地图墙 / 收藏]
```

这是拓扑示意，不是最终尺寸。空间尺寸需按编辑器、角色速度、镜头和碰撞白盒验证。

## 3. 区域卡

### A. 铅笔盒小镇

情绪：温暖、安全、有人生活。
地标：深青绿色铅笔盒外壳/拉链、布棚小店、暖窗灯、探险工作间、远处书谷和台灯。
玩法：基础移动与交互教学；地图和手册；发现基地；接到修复书谷道路的委托。
居民：首版 2--3 个固定行为居民，不做复杂日程 AI。

### B. 书谷

情绪：好奇、尺度震撼、轻微危险但安全可控。
地标：两本巨大书形成峡谷，书脊、页边、封面布料、纸张纤维，尺子桥。
玩法：观察支点、整理模式搭桥、实际过桥、可选替代路线、发现旧地图碎片。

### C. 文具荒野（后续）

情绪：冒险、活泼、组合挑战。
地标：铅笔轨道、橡皮平台、回形针挂钩、橡皮筋机关。
玩法：组合机关、捷径、环境变化。首版不制作完整内容。

### D. 杯岸港口（后续）

情绪：宁静、辽阔、旅程终点。
地标：陶瓷杯港湾、杯柄环路、微缩码头、灯塔、船只、水面反射。
玩法：港口路线、航标修复、观景、最终灯会。首版不做真实水体物理。

## 4. 首个关卡分段

  段落       目的       玩家行为
  ---------- ---------- --------------------
  起点平台   目标可见   看见对岸小镇入口
  观察区     识别物件   查看尺子与支点
  编辑区     整理模式   摆放尺子
  过桥区     实际验证   走过尺子桥
  对岸平台   成功反馈   灯亮、居民回应
  观察终点   预示后续   看见书页高台和远景

## 5. 关卡规则

-   进入区域后 5--10 秒内能看见目标。
-   可交互物件有清晰视觉差异，不靠 UI 标注一切。
-   支点与尺子的长度关系通过构图自然表达。
-   过桥有空间感但不频繁掉落。
-   成功后至少一个世界状态变化。
-   摆放可重置，不消耗资源。

## 6. 导航

简化地图显示已探索区域、当前位置、主要目标。优先依赖台灯、书脊、铅笔盒、杯子等地标，不持续显示箭头。提供安全点重定位。

## 7. 动态事件

后续可加入翻书、台灯开关、铅笔放下、居民使用新路等事件。必须有预兆，不随机伤害玩家，不破坏谜题状态。

## 8. 每个区域的内容层

主路线、居民支线、隐藏地点、物件挑战、视觉奇观。每个区域至少引入一种新空间规则，不要一次堆太多新系统。
