# TASK PACK 001｜团队启动与首轮验证

> 项目：《天空列车的最后一站》The Last Terminus  
> 阶段：M0 — Design-to-Editor Proof & Graybox  
> 适用团队：总设计师 1 人 + 造世界编辑器操作者 3 人  
> 目标：先证明设计、资产、编辑器、Git 和跨成员交接能够闭环，再进入高成本美术生产。

## 0. 这不是完整七天制作任务

本任务包是第一批开工任务，不要求三个人在第一天做出完整世界。

第一阶段只完成：
1. 统一理解项目已确认范围。
2. 验证新版造世界 AI 编辑器的真实项目、资产导入、保存和交接能力。
3. 三个世界各自完成可评审的空间白盒。
4. 两个可玩世界各完成一个最小玩法探针。
5. 确认后续美术、音乐和玩法生产的真实边界。

禁止在技术链路尚未验证时批量生成模型、制作精细场景或假定场景能够合并。

## 4. 阶段顺序

### Gate 0｜读懂项目
三人分别提交不超过 10 条的理解摘要，并指出自己任务的未知项。不要先建模。

### Gate 1｜技术探针
A 牵头，B/C 配合。验证项目保存、重新打开、GLB/WPRE 导入、Git 克隆和跨电脑打开。具体能力只以实际操作证据为准。

### Gate 2｜世界白盒
B、C 分别制作低成本空间白盒；A 制作列车公共空间白盒。先用基础形体表达尺度、路线、入口、出口和主要地标。

### Gate 3｜玩法探针
B 验证一个“日常物件被重新利用”的交互；C 验证一个“通过观察空间结构发现路线”的交互。若编辑器不支持预想机制，必须给出可运行的降级方案。

### Gate 4｜设计评审
总设计师根据真实截图、连续录屏和实测报告决定是否进入精细美术生产。未通过 Gate 1 的内容不得进入大批量生产。

## 5. 阶段完成定义

本任务包完成时必须具备：
- 一份真实的编辑器能力报告。
- 一份资产导入/交接报告。
- 一份 Git 克隆与恢复验证记录。
- 列车、书桌站、失重花园三个白盒。
- 两个可玩世界各一个最小交互演示。
- 每个成员一份证据齐全的阶段报告。
- 总设计师对下一阶段范围的明确结论。

## 6. 项目范围保护

本阶段不做：
- 《梦境邮局》。
- 第四个世界或额外站点。
- 复杂列车驾驶。
- 真实任意方向重力。
- 大量 NPC、完整文明模拟、复杂任务系统。
- 未经验证的大批量 AI 模型生成。
- 只为截图服务、没有路线和玩家体验的空场景。

**先证明一条生产链路能工作，再复制这条链路。**
