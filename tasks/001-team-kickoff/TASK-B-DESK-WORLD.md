## 2. 本世界的体验定位

主题：微观尺度、日常物件再利用、探索与创造。

玩家进入一张巨大书桌构成的微缩文明。书本像峡谷，尺子像桥，铅笔盒像小镇，杯子像港口。

玩家不是在普通桌面上散步，而是进入一个具有真实生活痕迹、可探索路线和尺度反差的微缩世界。

本轮核心记忆点：
**玩家亲自利用一件普通物品，改变原本无法通过的空间，并真正走过新路线。**

## 4. 工作包 B2：空间白盒

### 本轮只做一个连续小区域

空间顺序：
1. **书脊站台：** 玩家出生点。让玩家第一眼看到巨大的书本和尺子桥。
2. **书谷：** 两本巨大书形成的峡谷，主路线在这里中断。
3. **尺子桥：** 本世界核心地标和玩法位置。
4. **铅笔盒小镇入口：** 通过尺子桥后可见的小型生活区域。
5. **杯岸港口：** 可以作为远景地标；本阶段不要求可达。

### 白盒要求
- 先用编辑器基础形体或占位模型，不要先做精细模型。
- 从出生点能看到主地标或明确方向。
- 玩家能判断主路线和支路。
- 书本、尺子、铅笔盒、杯子之间要有明确比例关系。
- 玩家不能被无意义装饰挡住路线。
- 至少设置一个可选观景点或短支路。

### 交付
- 场景全景截图。
- 入口到终点的俯视/路线图。
- 从出生点连续走到铅笔盒小镇入口的录屏。
- 主要物体的尺寸/比例记录（使用编辑器实际单位，不要猜）。

## 5. 工作包 B3：最小玩法探针——尺子桥

### 玩家体验
1. 玩家到达书谷，看到两本书之间有一道无法直接跨越的缺口。
2. 玩家注意到附近的尺子和两个支撑点。
3. 玩家利用尺子改变通行条件。
4. 玩家实际走过尺子桥。
5. 抵达对岸后，出现明确反馈，例如小镇灯光亮起、路线标记更新或一处门/路径开放。

### 实现优先级
- P0：证明“物件被重新利用后，玩家能通过新路线”。
- P1：如果编辑器支持稳定的对象拖放/吸附/交互，尝试把尺子移动到两个锚点之一。
- P2：多解方案（例如尺子桥或书页坡道），只有在低成本且稳定时才做。

### 降级方案
如果新版编辑器不支持自由物理摆放：
- 用一个交互触发器控制尺子桥从收起状态变为展开状态；或
- 用可交互的固定物件触发桥梁显现。
- 必须保留“普通物件改变空间通行”的概念，不能降级成普通捡钥匙开门。

### 交付
- 完整玩法流程录屏。
- 触发方式和配置步骤。
- 成功、失败和重置行为说明。
- 编辑器能力限制记录。

## 6. 工作包 B4：核心美术资产清单

优先级如下：

| 优先级 | 资产 | 用途 |
|---|---|---|
| P0 | 两本大型书 | 书谷空间主体 |
| P0 | 木质尺子 | 核心玩法道具 |
| P0 | 铅笔盒小镇入口 | 站点识别地标 |
| P1 | 台灯 | 远景光源和尺度参照 |
| P1 | 陶瓷杯/杯柄港口 | 远景地标 |
| P1 | 纸张、回形针、铅笔、橡皮 | 环境细节和次级交互 |
| P2 | 大量居民、复杂室内 | 本轮不优先 |

### Tripo / Blender 规则
- 先审计现有模型，缺失才生成。
- Tripo 每次只做一个明确资产，不要一次生成整个场景。
- 对尺子、书本等核心资产提供正/侧/细节参考。
- Blender 检查比例、原点、法线、UV、贴图和碰撞代理。
- 导出 GLB 后必须回到造世界编辑器实测。
- 概念图不是生产资产。

## 7. 音乐与声音

本阶段只提交声音需求，不要求独立制作音乐：
- 主音乐情绪：温暖、好奇、轻盈，有微缩生活感。
- 环境声：纸张摩擦、木质轻响、远处小镇生活声、台灯电流/环境声（按实际可用资源选择）。
- 核心交互：尺子落位、桥梁展开、成功通行的短反馈。
- 找到候选音乐时必须记录作者、链接、许可证和署名要求。
