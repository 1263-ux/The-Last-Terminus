## 2. 本世界体验定位

主题：方向、垂直空间、路线发现。

玩家来到一座漂浮在云层之间的花园。巨型花朵、倒悬温室和悬挂根系构成空间结构。道路不再只沿着地面延伸，玩家需要观察环境，发现通向中央温室的路线。

本世界的核心记忆点：
**玩家第一次发现，一条看似不可能通行的路线，其实一直就在眼前。**

## 3. 工作包 C1：地形和空间白盒

### 空间必须有三个层级

1. **下层：入口浮岛/云上花海**
   - 玩家出生点。
   - 能看到中央温室或巨型花朵。
   - 让玩家理解这是一个漂浮世界。

2. **中层：根系长廊**
   - 连接不同高度的路线。
   - 至少有一个视线遮挡或路线判断点。
   - 允许玩家观察上层和下层的空间关系。

3. **上层：倒悬温室/中央花园**
   - 本世界主要目标和视觉地标。
   - 玩家抵达后能俯瞰整个花园。
   - 作为主要体验终点。

### 白盒要求
- 先用 AI 地形或基础形体搭空间，不要立即生成大量花朵。
- 先确认角色移动、平台碰撞和路线可达。
- 三层之间要有可解释的连接方式。
- 入口 5–10 秒内能看到主要地标。
- 不依赖真实任意方向重力。
- 不使用强制镜头翻转或容易眩晕的路线。

### 交付
- 全景截图。
- 俯视/路线图。
- 从入口到中央温室的连续录屏。
- 三个层级的空间关系说明。

## 4. 工作包 C2：最小玩法探针——寻找另一条路

### 玩家体验
1. 玩家从下层浮岛出发，看见上层中央温室。
2. 直接道路被断开或遮挡。
3. 玩家观察巨型花朵、根系和平台的朝向。
4. 玩家发现一条沿侧面/下方延伸的替代路线。
5. 通过一个移动平台或预设连接点抵达中层。
6. 沿根系长廊到达上层温室。
7. 到达后获得视野奖励（例如花园灯光亮起、花朵展开或环境音变化）。

### 实现优先级
- P0：玩家能通过观察发现一条非直线的空间路线。
- P1：如果移动平台组件经过实测可用，加入一次平台移动。
- P2：如果编辑器支持且稳定，可加入一个局部视角/路径切换。
- 不要求真实重力方向变化。

### 降级方案
如果移动平台不稳定：
- 使用静态错层平台 + 一个短距离传送/预设连接。
- 通过遮挡、转角和视线变化制造“发现新路”的感觉。
- 玩法仍必须由玩家主动观察并选择路线，不能只做一条普通楼梯。

### 交付
- 完整玩法录屏。
- 平台/传送/触发配置说明。
- 失败和重置行为说明。
- 哪些功能已实测、哪些仍待验证。

## 5. 工作包 C3：核心美术资产

| 优先级 | 资产 | 用途 |
|---|---|---|
| P0 | 浮空岛地形 | 三层空间基础 |
| P0 | 中央倒悬温室 | 主视觉地标 |
| P0 | 一株巨型花朵 | 方向错位的识别物 |
| P1 | 悬挂根系/藤蔓 | 连接路线 |
| P1 | 玻璃结构和平台 | 空间层次 |
| P1 | 发光植物 | 局部视觉焦点 |
| P2 | 大量小花、昆虫、居民 | 本轮不优先 |

### 资产制作规则
- 地形优先用造世界 AI 地形工具生成，再人工塑形。
- 核心温室和巨型花朵可用 Tripo 辅助生成。
- 普通植物、石块、草地优先使用成熟资产。
- Blender 处理模型比例、网格、材质、法线、UV、碰撞代理。
- GLB 导入造世界后检查贴图、缩放、层级和碰撞。
- 不要把“失重”理解成必须给所有模型添加发光材质。

## 6. 美术和音频方向

视觉气质：
- 空灵、安静、奇妙。
- 主色暂定薄荷绿、淡紫、天蓝。
- 材质以植物、玻璃、根系、少量晶体为主。
- 控制发光物体数量，避免高饱和荧光拼盘。
- 必须保留清晰的玩家路线和安全落脚点。

音乐情绪：
- 轻盈、空灵、缓慢、有漂浮感。
- 环境声：风、叶片、藤蔓摩擦、玻璃轻响、远处水声。
- 交互反馈：平台移动、花朵展开、抵达温室。

候选音乐必须记录作者、来源、许可证和署名要求。

## 7. 本阶段禁止事项

- 不做真正任意方向重力系统。
- 不做多个大型岛屿和复杂传送网络。
- 不做复杂 NPC 文明。
- 不做大量可交互植物。
- 不重复书桌站的“收集零件搭桥”玩法。
- 不在空间路线和碰撞未通过前批量制作精细模型。
