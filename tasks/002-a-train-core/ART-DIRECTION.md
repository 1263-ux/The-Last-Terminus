# 美术方向｜原创视觉基线与参考图使用

## 1. 原创方向

本项目建议探索 **高品质风格化 3D 童话冒险**：
- 有真实材质触感，但不追求写实扫描感。
- 有手工制作的细节和温暖的生活痕迹。
- 轮廓清楚、构图有层次、主地标容易识别。
- 光线柔和但有方向，远景有空间层次。
- 世界可以奇妙，但不能杂乱或廉价堆砌。

整体温馨、治愈、唯美，允许局部神秘和宏大感。

## 2. 本轮原创概念参考图

当前对话中生成了一张四分区原创视觉探索板，分别表现：
- 复古天空列车。
- 温暖的列车观景车厢。
- 书桌微缩世界。
- 云海中的浮空花园。

它是方向探索图，不是最终设定、生产模型或必须照着搭建的场景。A/B/C 应从中提取光色、空间氛围、材质对比和画面层次，再结合成熟项目研究发展自己的方案。

## 3. 各世界视觉识别

| 世界 | 视觉关键词 | 主要材质方向 | 画面重点 |
|---|---|---|---|
| 列车 Hub | 温暖、复古、可信、旅程感 | 木材、深色金属、黄铜、玻璃、织物 | 室内暖光与窗外云海形成对比 |
| 书桌站 | 微观、生活痕迹、奇妙、亲切 | 纸张、木材、陶瓷、布料、文具 | 巨大日常物件与玩家尺度反差 |
| 失重花园 | 空灵、垂直、植物、空间错位 | 玻璃、植物、根系、石材、少量晶体 | 上下层次、倒悬结构和路线发现 |
| 云海尽头 | 宏大、宁静、抵达、回望 | 石材、金属、玻璃、云雾 | 主地标、观景路线和远景云海 |

## 4. 美术参考图如何使用

参考图不是让 Agent 复制场景，而是帮助它理解：
- 构图和镜头。
- 形体与轮廓。
- 材质和色彩关系。
- 光照与时间氛围。
- 空间尺度和玩家位置。
- 场景中哪些元素承担视觉引导。

每位成员应先做参考分析，再给出自己的方案。允许组合多个参考的设计方法，但必须形成原创场景。

## 5. 质量判断

- 远景有主地标和空间层次。
- 中景能看清玩家路线和建筑关系。
- 近景有可信材质、干净轮廓和合理连接。
- 模型不漂浮、不穿插、不明显破面。
- 不同来源资产经过统一材质和色彩处理。
- 不靠强雾、景深、泛光掩盖模型问题。
- 游戏运行视角下仍然好看，而不只是编辑器自由视角好看。
