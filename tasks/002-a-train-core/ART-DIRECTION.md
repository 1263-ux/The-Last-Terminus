# 美术方向｜Train Hub & Final Terminus

状态：整体质量基线为项目提案；列车外观和终点站主地标仍需总设计师最终批准。上一轮生成的列车/终点站概念图只作为探索稿，不视为最终定稿或生产模型。

## 1. 总体风格目标

**Premium Stylized Storybook 3D｜高品质风格化童话 3D**

关键词：
- 可信的实体材质，而不是塑料玩具质感。
- 手工制作感的建筑细节。
- 柔和但有方向性的电影级光照。
- 轮廓清晰、构图有层次。
- 细节丰富，但主路线和主地标一眼可读。
- 温暖、安静、略带神秘，不做过度蒸汽朋克或科幻机甲。

不采用：
- 低多边形积木风。
- 过度写实的 PBR 工业仿真。
- 满屏齿轮、管线、烟雾和发光符号的“廉价蒸汽朋克”。
- 过饱和霓虹。
- 用强景深、泛光或浓雾掩盖模型质量问题。

## 2. 列车视觉方向（候选）

推荐先探索“古老、真实、略带神秘的复古机械列车”：
- 主体候选色：深青绿/墨绿。
- 辅助色：暖木色、奶油白。
- 金属：做旧黄铜/暗金。
- 灯光：暖琥珀色。
- 细节：真实轮组、连接件、车窗框、车灯、铆钉和少量装饰纹样。

这只是候选，不代表已经锁定蒸汽动力或具体年代。不要自行添加大量蒸汽朋克管线，也不要复制任何现成游戏列车造型。

## 3. 列车 Hub 色彩与材质

| 元素 | 候选色/材质 | 视觉要求 |
|---|---|---|
| 车厢外壳 | 深青绿/墨绿金属 | 哑光偏柔，边缘有轻微磨损 |
| 内墙 | 深胡桃木/暖木饰板 | 纹理方向一致，不做过度高反射 |
| 地板 | 暖木/深色耐磨材质 | 纹理尺度与玩家比例匹配 |
| 金属边框 | 做旧黄铜 | 小面积高光，不能全车镀金 |
| 座椅 | 奶油白/深酒红布料 | 织物质感，避免塑料皮革 |
| 灯具 | 暖琥珀玻璃 | 发光范围受控，保留灯具实体 |
| 路线图 | 纸张/黄铜/玻璃 | 有实体装置感，信息清晰 |

## 4. 云海尽头色彩与材质

| 元素 | 候选色/材质 | 视觉要求 |
|---|---|---|
| 主建筑 | 暖白石材/奶油色 | 柔和、干净、略有岁月痕迹 |
| 建筑结构 | 暗金属/黄铜 | 作为结构和标识点缀 |
| 玻璃 | 低饱和暖反射 | 不做强镜面 |
| 站台地面 | 浅灰暖石材 | 纹理细节克制，保证路线可读 |
| 灯具 | 暖金色 | 与列车车窗灯形成统一识别 |
| 天空/云海 | 金色夕照、浅蓝灰、奶白 | 有前中远景层次，不要全部橙色 |
| 远景浮岛 | 低饱和蓝灰/暖灰 | 仅作轮廓，不抢主地标 |

## 5. 灯光方案

### 列车 Hub
- 主光：车厢内暖色灯具。
- 环境光：窗外冷色云海/天空补光。
- 对比：内暖外冷，强化“安全的移动家园”。
- 避免：车厢过暗、窗户过曝、黄铜大面积发白。

### 云海尽头
- 主光：低角度夕阳/日出暖光。
- 环境光：云海提供柔和反射。
- 建筑阴影：保留柱廊、屋檐、钟楼的体积感。
- 远景：轻雾分层，不让雾吞掉地标。
- 终点观景台：让玩家面向光线和开阔视野，但不要直射镜头导致过曝。

## 6. 视觉验收机位

每个场景至少交付：
- 远景：空间关系、主地标、云海层次。
- 中景：玩家路线、列车/建筑的空间关系。
- 近景：模型边缘、材质、接缝、金属和木材细节。
- 反向机位：从终点回望入口，检查路线闭环。
- 用户视角：在实际运行状态下观察，不只使用编辑器自由相机。

## 7. 质量判断

核心资产必须满足：
- 轮廓干净，没有明显破面、缺口和异常薄片。
- 纹理尺度符合玩家距离，木纹/石纹不夸张。
- 材质粗糙度有区分，不能所有表面一样亮。
- 连接处合理，没有明显漂浮、穿插和不合理悬空。
- 从玩家视角能读出入口、道路、台阶、门和交互位置。
- 远景有层次，近景有细节，中景不混乱。

## 8. 参考图使用

总设计师上一轮生成的列车终点站图属于概念探索参考。A 应将其拆成：
- 构图：列车、站台、主建筑、云海的相对关系。
- 轮廓：车头、车厢、拱廊/钟楼的外形层次。
- 材质：深色金属、黄铜、石材、木材。
- 光照：暖色车窗/灯具与冷暖天空对比。

不允许直接把 AI 概念图当贴图、模型或已完成的场景。
