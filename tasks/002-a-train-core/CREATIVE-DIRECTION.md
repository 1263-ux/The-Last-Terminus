# Creative Direction｜美术、音乐与玩法的总体方向

这份文件为三个世界提供共同的创作方向。它不是完整 GDD，也不预先规定每个谜题、每段音乐或每个模型。各成员和 Agent 应在这些方向内提出自己的方案、做小样、比较和迭代。

## 1. 作品整体气质

**温馨、治愈、唯美，逐渐出现神秘与感动。**

我们希望玩家感觉自己搭乘一列古老而可信的天空列车，穿过三个尺度和空间规则不同的世界。旅程短，但每个世界都应该留下一个清晰的记忆点。

统一性来自：
- 同一列车和旅程线索。
- 一致的玩家尺度、镜头可读性和交互反馈。
- 统一的模型质量、材质可信度和声音完成度。

差异性来自：
- 每个世界独有的形体、色彩、材质和空间逻辑。
- 每个世界不同的核心玩法。
- 每个世界独有的环境声和音乐气质。

## 2. 三个世界的体验职责

### 书桌站《桌面以下》
- 关键词：微观、生活痕迹、发现、创造。
- 玩家体验：观察日常物件，重新理解它们的用途，用物件改变通行方式。
- 玩法方向：环境谜题、物件互动、有限自由度和多解。
- 记忆点：玩家亲自改变空间，并真正走过自己创造的新路线。

### 失重花园
- 关键词：空灵、垂直、方向错位、惊奇。
- 玩家体验：看到一个看似无法抵达的地标，通过观察环境发现另一条路。
- 玩法方向：空间路线发现、错层平台、视线和高度关系。
- 记忆点：玩家意识到道路不只在脚下，原来刚才看见的结构就是路。

### 云海尽头
- 关键词：抵达、安静、开阔、回望。
- 玩家体验：下车、漫游、逐渐接近主地标和最终观景点。
- 玩法方向：纯展示，不强行增加收集、解谜或战斗。
- 记忆点：玩家站在终点看见云海和来路，感到旅程结束。

## 3. 音乐设计方向

音乐应当像一条贯穿旅程的情绪线，而不是三个互不相干的背景曲。

**共同主题：列车主题动机。**
- 为列车设计一个容易记住、但不过度复杂的短音乐动机。
- 它可以在 Hub、启程、到站和最终结尾以不同编曲方式出现。
- 不要求复杂交响乐；先有一个好记的主题，再考虑变化。

**三个世界的音乐气质：**
- 书桌站：轻巧、温暖、有好奇心。可考虑木质打击、拨弦、钟琴或轻柔钢琴等音色。
- 失重花园：轻盈、空灵、有漂浮感。可考虑长音弦乐、柔和木管、玻璃般的高频点缀。
- 云海尽头：开阔、克制、带一点怀念。可以让列车主题在这里变得更完整、更舒展。

**声音设计重点：**
- 列车：车轮、制动、车门、汽笛和车厢环境声。
- 书桌站：纸张、木材、陶瓷、文具和微缩生活声。
- 失重花园：风、叶片、根系、玻璃和远处水声。
- 云海尽头：开阔风声、远处汽笛和空间环境声。

**实现原则：**
- 如果编辑器支持分层音乐或触发切换，可以尝试动态音乐。
- 如果不支持，使用每个世界一段主音乐，加少量过渡音效即可。
- 不为了动态音乐开发复杂音频系统。
- 优先使用有明确授权的现成音乐；也可以提出原创音乐需求。
- 记录来源、作者、许可证和署名要求。

参考方法：
- A Short Hike：音乐随区域变化，主旋律通过不同乐器层次形成变化。
- Sky：声音本身可以讲述环境，不必每个信息都用文字说明。
- Spiritfarer：音乐可以同时包含温暖与淡淡的忧伤，不必只有单一情绪。

## 4. 玩法设计方向

我们需要两个真正不同的可玩体验，而不是把同一个谜题换皮。

**书桌站：改变物件的用途。**
- 玩家观察物件和环境之间的关系。
- 通过有限的互动改变空间状态。
- 允许合理的替代解法。
- 成功后玩家亲自使用新路线。
- 不要求任意物理沙盒；可以用锚点、预设状态或组合交互实现。

**失重花园：改变玩家对空间的理解。**
- 玩家先看到目标，再发现直线路径不可用。
- 环境结构给出可观察的线索。
- 玩家主动寻找侧面、下方或上方的连接路线。
- 抵达后获得视野或环境反馈。
- 不要求真实重力反转；优先确保舒适、可读和稳定。

**云海尽头：不需要强行加玩法。**
- 让玩家自己走、看、停留和回望。
- 用构图、光线、环境变化和音乐形成收束。
- 纯展示也必须有空间节奏和探索路线。

## 5. 叙事方向

- 以环境叙事为主，短文本为辅。
- 列车、站牌、物件、灯光和建筑痕迹可以留下故事线索。
- 不必解释列车的一切秘密。
- 列车起源、云隙本体和终点真相仍是开放设定。
- Agent 可以提出故事解释，但必须标记 PROPOSED，不得擅自写成正式设定。

## 6. 给 Agent 的创作自由

在不改变上述体验职责和总体气质的前提下，Agent 可以：
- 提出多种视觉方案和空间布局。
- 自主决定具体模型、模块和场景组合方式。
- 根据编辑器能力调整交互实现。
- 对玩法提出替代解法。
- 对音乐和声音提出新的乐器、节奏和环境声方案。
- 通过小样比较后推荐更好的方案。

不要要求 Agent 只执行唯一提示词。更好的工作方式是：理解方向 → 提出方案 → 快速做样 → 实际试玩/对比 → 解释取舍 → 进入下一轮。
