## 2. 官方文档已明确的编辑器工作方式

### 2.1 项目入口与场景工作区
官方指南说明：
- 编辑器提供项目管理页面。
- “最近编辑”显示已有项目。
- 可以“新建空白项目”。
- 主场景包含场景层级、资产库、3D 视口和属性编辑面板。
- 场景层级用于管理地图、出生点、传送门等对象。
- 资产库包含建筑、自然、载具、道具、机关和动物等素材。
- 属性面板可修改对象位置、角度、大小和互动配置。
- 场景容量会显示当前使用量/总容量，例如 207/4000；该数字与发布和运行流畅性相关。

### 2.2 视口操作
官方指南介绍：
- 鼠标中键拖动：平移视角。
- 鼠标右键拖动：绕相机旋转。
- Option + 绕物体旋转：围绕选中对象观察细节。
- 方位指示球可切换顶视图、后视图等正交视图。
- 右键 + WASD 可从用户视角漫游。
- 移动/旋转/缩放工具在视口工具栏中。
- W/E/R、Delete/Backspace 被文档列为常见快捷键，但文档明确提醒应在当前编辑器内实测；若不生效，使用工具栏。

### 2.3 AI 地形与环境
官方教程说明：
1. 进入“地图生成”。
2. 输入地形描述，或上传参考图并补充描述。
3. 预览地形结果。
4. 满意后“启用该地形”。
5. 启用后可解析地表物体或自定义覆盖物描述。
6. 检查覆盖物并替换不合适资产。
7. 合成地图并导入当前场景。
8. 地形可通过隆起、凹陷、平滑等工具继续修改。

A 的终点站地形应先做大形体和空间边界，不要依赖 AI 一次生成全部建筑和装饰。

### 2.4 模型生成
官方指南区分：
- 一体铸造：生成不可拆分整体，适合建筑、植物、静态道具。
- 模块组装：由多个部件组成，模块可以单独运动，适合车轮、机械机关等。

这说明在模型需求阶段就必须明确是否需要独立活动部件。不要先做一个无法拆分的模型，之后再要求它做动画。

## 3. 用户已确认的外部资产能力

团队已实际确认新版编辑器支持导入：
- GLB
- WPRE

但以下属性不能仅凭格式推断，必须实测：
- GLB 材质和贴图是否完整保留。
- GLB 动画是否保留。
- GLB 层级/子部件是否保留。
- GLB 碰撞是否需要在编辑器重建。
- WPRE 是否包含全部依赖。
- WPRE 是否保留交互、碰撞、层级和外部引用。
- WPRE 能否跨账号/跨电脑无损导入。
- 导入后保存并重新打开是否正常。

## 4. 必须在编辑器内打开并核实的官方章节

官方目录包含以下章节，但当前任务不得凭目录标题假定具体参数：
- 保存、真机预览与调试。
- 格式、面数与容量限制。
- 逻辑交互。
- 静态模型与组合资产玩法。
- 发布合规与作品发布自查。

A 必须在当前编辑器版本中打开对应章节，记录：
- 具体菜单路径/操作步骤。
- 模型格式和大小限制。
- 面数/容量限制。
- 逻辑组件的输入输出与限制。
- 预览/调试流程。
- 上传前检查要求。

无法确认的内容写 TO-VERIFY，不得写成已支持。

## 5. A 的最小操作探针

### Probe 01：项目保存与恢复
1. 新建空白项目。
2. 放入一个基础模型。
3. 保存。
4. 关闭编辑器。
5. 重新打开项目。
6. 检查场景层级、模型、材质和位置是否恢复。
7. 记录项目真实目录和必要文件。

### Probe 02：GLB/WPRE 导入
1. 导入一个简单 GLB（至少有材质/贴图）。
2. 导入一个 WPRE 组合资产。
3. 检查层级、比例、材质、贴图、碰撞和交互。
4. 保存并重开。
5. 将文件交给 B 或 C 在另一台设备/账号测试。
6. 记录失败项和降级方式。

### Probe 03：世界连接
1. 在测试场景中放置两个明显分离的平台。
2. 查看场景层级和资产库中可用的传送门/逻辑交互组件。
3. 尝试建立 A 点到 B 点的传送。
4. 测试返回路径。
5. 录制连续操作。
6. 若不能连接两个场景，测试同一场景内的分区传送。

### Probe 04：音频
1. 导入一段短 WAV/MP3 候选音频（按编辑器实际支持格式）。
2. 测试能否播放、循环、停止、触发。
3. 检查是否有音量参数、淡入淡出或独立通道。
4. 如果不支持复杂混音，记录最简单可用方案。

## 6. 操作证据要求

每个 Probe 必须附：
- 编辑器版本截图。
- 操作前截图。
- 操作步骤录屏。
- 保存/重开后的截图。
- PASS / FAIL / NOT TESTED。
- 失败复现步骤。
- 当前版本/账号/设备信息。

不要用网上其他版本的界面截图替代当前编辑器实测。
