# 阶段 Gate、时间盒与验收

## 1. 总体原则

- 每个 Gate 都必须有 Owner、输入、产物、通过条件和失败降级。
- P0 技术阻塞未解除，不得进入大规模精细美术。
- 每个 Gate 的结果都要能通过文件、截图、录屏或重新打开的项目验证。
- 时间盒是控制投入的上限，不代表到时间就可以跳过验收。

## 2. Gate 列表

| Gate | 时间盒建议 | Owner | 目标 | 是否阻塞下一阶段 |
|---|---:|---|---|---|
| A0 设计理解与 Agent 配置 | 30–45 分钟 | A | 理解一致、执行计划通过 | 是 |
| A1 项目/Git/资产探针 | 90–150 分钟 | A | 本地项目和 GLB/WPRE 交接有真实结论 | 是 |
| A2 列车 Hub 白盒 | 60–90 分钟 | A | 公共空间和路线图结构成立 | 是 |
| A3 世界接口与连接探针 | 60–120 分钟 | A + B/C | 至少一种连接方案实际可用 | 是 |
| A4 云海尽头白盒 | 90–120 分钟 | A | 到站—主地标—观景路线完整 | 是 |
| A5 关键资产导入与美术精修 | 按资产分块 | A + 总设计师 | 核心资产达到视觉目标 | 否，非关键装饰可降级 |
| A6 音频与最终集成 | 90–150 分钟 | A | 完整旅程可运行 | 是 |
| A7 最终 QA 与交付 | 60–120 分钟 | A + 全体 | 完整旅程证据齐全 | 是 |

## 3. Gate 0｜设计理解与 Agent 配置

输入：
- 项目 World Bible。
- A 任务包。
- 官方编辑器文档。

通过条件：
- A 能说明本任务目标、边界、开放设定。
- Claude/GPT 角色职责清楚。
- 已列出技术未知项。
- 已建立项目文件所有权。

交付：
- reports/A0-understanding-and-plan.md
- Agent team plan / task board

失败降级：
- 如果 Agent 团队工具不支持并行子代理，按角色顺序执行，不阻塞任务。

## 4. Gate 1｜项目、Git、GLB/WPRE 探针

通过条件：
- 项目能保存、关闭、重新打开。
- 能记录真实项目目录和必要文件。
- GLB 导入有成功/失败矩阵。
- WPRE 导入有成功/失败矩阵。
- 至少一名其他成员完成获取/克隆/打开/修改/回传。
- 能明确项目文件、缓存和临时文件边界。
- 未知项没有被误写成已支持。

交付：
- A1 报告。
- 资产导入测试文件。
- 操作录屏。
- 推荐 Git 规则和最小 .gitignore。

失败降级：
- 若完整工程无法跨电脑迁移，先尝试独立 WPRE/GLB 交接。
- 若 WPRE 不保留交互，交付纯资产并由 A 在主项目重建交互。
- 若 Git 对场景二进制无法合并，明确单一写入者和快照集成策略。

## 5. Gate 2｜列车 Hub 白盒

通过条件：
- 玩家出生点清楚。
- 能辨认观景窗、路线图、入口/出口。
- 主通道无阻挡。
- 车厢比例以角色 H 为参照合理。
- 从出生点到离站门可以走通。
- 视口截图和用户视角录屏齐全。

交付：
- Hub 白盒场景。
- 俯视布局图。
- 远/中/近景截图。
- 连续录屏。

## 6. Gate 3｜世界接口与连接探针

通过条件：
- B/C 的 Entry/Exit Anchor 规范已收到。
- A 能复现每个锚点的位置和朝向。
- 至少一种跨世界连接方式真实运行。
- 玩家返回列车后能继续下一站。
- 连接失败时有经过验证的降级方案。

交付：
- WORLD-INTERFACE-CONTRACT.md。
- 连接配置说明。
- 完整连接录屏。

## 7. Gate 4｜云海尽头白盒

通过条件：
- 终点站台、主建筑、云海步道、观景台四段空间可辨认。
- 从出生点能看见主地标。
- 从列车下车到观景台可以走通。
- 观景台视野明显优于入口视野。
- 玩家不能轻易掉出场景。
- 终点有回望车站/列车的机位。

交付：
- 白盒场景。
- 俯视路线图。
- 四个标准机位截图。
- 连续试玩录屏。

## 8. Gate 5｜美术资产导入与精修

通过条件：
- 总设计师已批准列车/终点站视觉方向。
- P0 Tripo 资产已由总设计师生成并交付。
- GLB 导入无严重材质、贴图、比例和法线问题。
- Blender 修整记录完整。
- 远/中/近景均达到当前美术基线。
- 编辑器容量未超限。

交付：
- 资产清单。
- 导入验收报告。
- 精修场景截图。
- 更新后的场景文件/资产包。

## 9. Gate 6｜音频与最终集成

通过条件：
- 列车声音标识能被听见但不压过环境。
- Hub 与终点站音量平衡。
- 音频来源和许可证登记。
- B/C 两个世界能按旅程顺序进入。
- 返回列车和进入下一站的流程无软锁。
- 保存后重新打开，场景和资源仍正常。

交付：
- 集成版本。
- 音频资产登记。
- 完整旅程录屏。
- P0/P1 问题清单。

## 10. Gate 7｜最终 QA

检查：
- 项目可重新打开。
- 所有入口/出口可复现。
- 玩家不会出生在模型内部或危险边缘。
- 主路线没有严重遮挡、穿模和碰撞缺口。
- 终点观景台具有明确视野奖励。
- 主要模型没有明显破面/缺材质/错误比例。
- 音频没有突兀爆音、长时间静音或重复叠加。
- 资产来源和许可证有记录。
- Git 有可恢复的稳定版本。
- 完整旅程连续录屏可观看。

## 11. 统一汇报模板

每个 Gate 提交：
- Gate ID / 日期 / 编辑器版本。
- 本轮目标和实际完成。
- 修改的项目/场景/资产。
- PASS / FAIL / NOT TESTED。
- 真实截图和录屏链接。
- 问题复现步骤。
- P0/P1/P2 级别。
- 已尝试方案和降级建议。
- 是否请求总设计师批准。
