# 空间设计意图｜列车 Hub 与云海尽头

本文件提供体验和空间关系，不规定固定尺寸、坐标或唯一布局。A 应通过白盒探索最适合当前编辑器和玩家视角的方案。

## 1. 列车 Hub

核心感觉：温暖、安定、带一点神秘感的移动家园。

玩家进入后应自然理解：
- 自己身处一列列车。
- 列车正在连接不同世界。
- 这里可以短暂停留、观察窗外、查看旅程和选择下一站。
- 离开列车后仍能回到熟悉的空间。

可以探索的空间元素：
- 观景窗和窗外云海。
- 旅程地图/站点信息。
- 少量座椅、灯具、行李或旅程物件。
- 一个能体现列车身份的标志性结构。
- 清楚的入口、出口和返回方式。

不要把车厢做成堆满家具的展示间，也不要做成纯 UI 菜单。

## 2. 世界连接

统一的体验顺序是：
列车 → 书桌站 → 列车/下一站 → 失重花园 → 列车/终点 → 云海尽头。

具体技术实现不预设。A 与 B/C 共同确认：
- 玩家从哪里进入。
- 出生时面向哪里。
- 如何返回列车或前往下一站。
- 进入和离开时是否需要短过场。
- 失败时如何恢复。

## 3. 云海尽头

核心感觉：抵达、安静、开阔、回望。

空间应让玩家经历：
1. 识别列车已经抵达终点。
2. 下车并理解车站与主地标的关系。
3. 沿自然路线探索。
4. 逐渐看到更开阔的云海。
5. 抵达值得停留的最终观景点。
6. 回望车站和来路，感受到旅程完成。

主地标可以是钟楼、灯塔、穹顶站厅、拱廊或新的原创构思。由 A 研究并提出方案，不要机械照搬参考项目。

## 4. 构图检查

请从玩家视角检查：
- 出生点是否能理解方向。
- 主地标是否容易识别。
- 路线是否自然，不需要持续箭头指引。
- 前景、中景、远景是否有层次。
- 终点视野是否比入口视野更有奖励感。
- 回望时能否看到列车或站点的记忆点。

空间设计应通过白盒和试玩验证，不要用精确比例表代替实际体验。
