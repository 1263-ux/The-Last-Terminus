# TASK PACK C｜失重花园

Owner：成员 C | World Type：Playable | Status：DESIGN BRIEF

核心体验：空间错位感 + 垂直探索 + 路线发现。

玩家进入漂浮花园，看到一个似乎无法抵达的目标，通过观察花朵、根系、温室、平台和不同高度的连接发现另一条道路。

本世界不做真实任意方向重力模拟。任务包定义体验、视觉、参考和验收；具体实现由 C/DSH 根据编辑器能力探索。
