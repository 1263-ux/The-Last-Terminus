## 0. 全项目统一视觉基线

- 高品质风格化 3D，材质有真实触感和手工细节。
- 画面温馨、治愈、唯美，局部允许神秘感。
- 远景建立尺度，中景说明路线，近景体现材质。
- 核心地标轮廓明确，玩家视角下可见。
- 不能用过量雾、景深、泛光掩盖模型问题。
- 美术图必须服务于可玩路线；概念图不是生产资产。

### 参考项目与学习重点

| 参考 | 学习什么 | 本项目原创转化 |

| Spiritfarer | 移动家园、空间功能组织、旅程记忆 | 列车是可返回的熟悉空间，少量地图/纪念物承载旅程 |

### A-01 列车 Hub 构图示意

~~~mermaid
flowchart LR
  W[观景窗：云海/远方世界] --- C[车厢主空间]
  M[旅程地图/下一站提示] --- C
  S[座椅/行李/少量纪念物] --- C
  C --- D[车门/站点入口]
  C --- R[安全返回点]
~~~

检查：
- 玩家第一眼知道自己在列车里。
- 窗外有可辨认的云海层次。
- 旅程地图能表达三个站点，不做复杂 UI 系统。
- 入口/出口位置明确。
- 不把车厢做成家具堆积的展示间。

### A-02 云海尽头构图示意

~~~mermaid
flowchart TD
  T[列车停靠/站台] --> A[识别主地标：钟楼/站厅/灯塔等原创形体]
  A --> P[自然漫游路线：拱廊/平台/坡道]
  P --> V[最终观景点]
  V --> H[云海远景 + 对前两站的视觉呼应]
  V --> L[回望列车与站台]
~~~

近/中/远景：
- 近景：站台、轨道、灯具、扶手、列车门。
- 中景：站厅/拱廊/主地标。
- 远景：云海、远方浮岛、书桌站灯光、花园轮廓。

本轮范围：一处列车停靠区 + 一个主地标 + 一条观景路线 + 一个最终视野。不要增加大型 NPC 城镇或驾驶模拟。

### A-03 声音参考

- Hub：暖机械底噪、轻轨道节奏、车门/汽笛提示。
- Terminus：减少节奏感，扩大空气感，收束旅程主题。
- 先用已验证可播放的音频路径，必须有人耳实听确认。

### B-01 主空间构图示意

~~~mermaid
flowchart LR
  S[书脊站台/出生点] --> C[书谷：两本巨书形成峡谷]
  C --> R[REST 尺子：可观察的核心物件]
  R --> I[玩家主动交互区]
  I --> G[RAMP 六段可见坡道]
  G --> T[铅笔盒小镇入口]
  C -.可选支路.-> O[书页/布料/回形针观景点]
  T -.远景提示.-> M[杯岸港口：本轮可只做远景]
~~~

### B-02 视觉层次

**远景**：台灯作为“太阳”，杯岸港口作为远方地标，小镇暖窗提供目标感。

**中景**：两本书形成书谷，尺子横跨缺口，玩家能看清 REST/RAMP 状态差异。

**近景**：尺子刻度、木材/塑料纹理、书页纤维、书脊布纹、支点和落脚区。

### B-03 材质与灯光

| 对象 | 材质表达 | 禁止方向 |
|---|---|---|
| 书本 | 纸张纤维、磨损页边、布纹书脊 | 不要像岩石峡谷 |
| 尺子 | 清楚刻度、边缘倒角、轻微磨损 | 不要塑料玩具感 |
| 铅笔盒小镇 | 拉链、隔层、圆角、布棚、暖窗 | 不要普通中世纪村庄换皮 |
| 陶瓷杯 | 釉面、杯沿厚度、杯柄弧度 | 不要平滑无厚度的圆柱 |
| 台灯 | 暖主光、可读灯罩和关节 | 不要过曝成一团白光 |

### B-04 玩法状态示意

~~~mermaid
stateDiagram-v2
  [*] --> REST
  REST --> Interaction: 玩家主动进入/使用绑定交互
  Interaction --> RAMP: REST隐藏 / RAMP_1..6显示
  RAMP --> Town: 玩家连续走过新路线
  Town --> Feedback: 灯光/音效/场景反馈
  Feedback --> Return: 返回列车
  REST --> SafeReset: 未解锁误入门禁区
  SafeReset --> REST
~~~

重要：物理墙不阻挡玩家。门禁由 Trigger/Lua 规则实现；画面必须解释为什么通路现在可用。不要预先同时摆好两个状态，也不要出生自动解锁。

### B-05 当前玩家相机可见角度预算

当前 B 工程实测：
topY <= 79.587 + (z - 85.3) * 0.0787，额外留 20% 余量。

这不是所有成员通用的世界公式。若 B 修改出生点、相机或 FOV，必须重测；A/C 不能直接复制该数值。

### C-02 三层空间剖面

~~~text
          [花冠层 / Crown Vista]
       巨型花朵、轻盈平台、观景
                    ↑
          [温室层 / Greenhouse]
       倒悬温室屋顶、可走结构
                    ↑
          [根系层 / Roots]
       根系长廊、断桥线索、隐藏路线
                    ↑
          [入口浮岛 / Entry]
       安全出生区、中央目标初见
~~~

### C-03 视觉结构

| 模块 | 重点 | 质量检查 |
|---|---|---|
| 浮空岛 | 岩层、土壤、根系、垂落结构 | 不能像悬浮方块 |
| 巨型花朵 | 花瓣层次、花心、茎和根 | 玩家可站立区域必须实测 |
| 根系长廊 | 粗细变化、分叉、弯曲、连接 | 可走根与装饰根清楚区分 |
| 倒悬温室 | 玻璃、框架、立柱、天窗方向线索 | 不能只靠上下颠倒旋转 |
| 观景点 | 花园全景、远方目标、回望来路 | 不能被栏杆/装饰遮挡 |

### C-04 观景验收视角

~~~mermaid
flowchart LR
  A[抵达花冠观景点] --> B[默认视角：下一目标可见]
  B --> C[玩家正常 Look-back]
  C --> D{3 秒内能识别来路？}
  D -->|是| PASS[视线验收 PASS]
  D -->|否| E[设计物理回转平台/短回转路线]
  E --> F[玩家主动转身后看到来路]
  F --> PASS
~~~

不允许脚本强制 yaw 或自动镜头接管。

### C-05 Backup Cue 演示流程

- t=0：玩家进入花园。
- t=0–45s：玩家自由探索，不重复催促。
- t=45s：若仍未发现路线，触发一次柔和光线提示；如音频已验证，再叠加一次短声音提示。
- 后续：同一次游玩不重复触发。
- 坠落：自动回到安全入口/检查点，玩家能继续。
- 重开：关闭并重新打开工程，再实测计时、去抖和恢复。

## 统一评审截图规范

每个世界提交至少：
1. 远景：整体布局和主地标。
2. 中景：玩家路线和关键互动。
3. 近景：核心资产材质和连接。
4. 玩家出生视角。
5. 最终目标视角。
6. 失败/恢复状态（如适用）。

所有截图必须来自实际造世界编辑器/实际运行，不得用 AI 概念图冒充已完成场景。
