# 《桌面以下》设计基线｜源档案提炼与造世界编辑器适配

> 来源：用户上传的《BelowTheDesk-精简档案-2026-11-20 (2).zip》中的 GDD v0.2、交互与谜题手册 v0.2、世界地图方案 v0.2、Art Bible v0.2、素材管线、音乐候选清单、垂直切片规格和决策风险记录。
>
> 本文保留源档案术语和设计意图；“编辑器适配”部分是针对当前新版造世界 AI 编辑器已验证限制所作的实施调整，不是原始 GDD 的原文。

## 1. 产品定位与四个体验支柱

**产品定位：** 第三人称微缩探索冒险 / 环境解谜 / 轻量建造 / 收藏与基地成长。

**一句话：** 在一张巨大书桌构成的微缩世界里，玩家作为独立探险者探索日常物件构成的地形，利用有限物件摆放与组合开辟道路、解决谜题、帮助居民，并建立自己的探险基地。

四个体验支柱：
1. **尺度奇观：** 熟悉的桌面物品成为山脉、桥梁、港口和建筑。
2. **创造性解谜：** 一个目标通常有一个主解法和一个替代解法，少数区域提供进阶捷径。
3. **世界回应：** 玩家修复的道路和设施会持续留在世界中，居民逐渐使用。
4. **探索归属：** 玩家拥有工作间、地图墙、收藏和旅程记录。

非目标：不是生存游戏、战斗 RPG、自由物理沙盒、重度资源经营或纯收集游戏；不做饥饿、口渴、装备耐久和强制刷材料。

## 2. 玩家身份与隐藏叙事

玩家是**独立探险者和地图绘制者**，不是被预言选中的救世主。玩家来到铅笔盒小镇，发现旧地图残缺，决定重新探索桌面、记录路线、帮助居民重新连接区域。

主角识别元素：围巾、探险背包、小灯、靴子。源档案未交付最终主角 GLB/动画，因此首轮使用编辑器可用角色或现有占位；不得声称定制主角资产已经交付。

隐藏叙事为“旧地图的主人”：儿童涂鸦、旧地图、纸飞机、便签和手写路线，暗示曾有一个孩子在这张桌面上创造和探索过这个世界，后来长大离开。不要强行煽情；通过环境叙事和收藏物逐步揭示，情绪落点是“曾经被认真想象过的地方，依然保留着温度”。

## 3. 核心循环

### 微循环
观察障碍 → 识别可用物件 → 推断用途 → 选择主/替代解法 → 摆放组合 → 实际通过 → 获得反馈。

### 区域循环
探索主路线和支路 → 完成关键谜题 → 帮助居民/发现秘密 → 解锁路线或物件知识 → 区域状态变化 → 地图更新。

### 长循环
探索新区域 → 获得纪念品/工具知识/地图信息 → 带回基地 → 解锁展示或轻量功能 → 形成新探索可能。

首个切片不实现完整基地成长系统，只保留轻量地图/知识记录或一个环境化的进度反馈。

## 4. 首个垂直切片

**时长目标：5–8 分钟，必须由试玩实测，不得靠重复收集填充。**

范围：
- 近侧书本平台、远侧书本平台和书谷；
- 木尺与两个支点；
- 铅笔盒小镇入口局部；
- 台灯、窗外背景和少量模块建筑；
- 主角使用现有角色/占位；
- 杯子只作远景地标。

体验流程：
1. 玩家在近侧书本平台进入。
2. 远处看见铅笔盒入口，中间是书谷。
3. 靠近尺子，触发观察提示。
4. 发现两个锚点，理解尺子可用于跨越。
5. 进入整理模式，选择尺子并摆放。
6. 预览合法后确认。
7. 尺子落位，完整桥体显示，路线状态改变。
8. 退出整理模式，实际走过桥。
9. 抵达小镇入口，灯亮，出现居民/环境反馈。
10. 地图或探险日志记录新路线。

## 5. 交互状态与谜题规则

原始交互状态：
- Exploration：角色移动、跳跃、观察。
- Inspecting：观察物件，显示用途提示。
- Planning：俯视/斜俯视摆放界面。
- Previewing：预览物件、锚点和连接结果。
- Committing：确认摆放，播放动画并更新关卡状态。
- Recovering：撤销、重置或回到安全点。

首批物件能力：
- 木尺：跨越、支撑、滑行，必须实现。
- 书页：坡道、遮挡，可先作为环境。
- 回形针：固定、连接、悬挂，是替代解法验证候选。
- 橡皮：配重、支撑、阻挡，作为环境物件。
- 橡皮筋、铅笔、纸翼暂缓。
- 陶瓷杯作为地标/港口/环形路线，首版只做远景。

第一版采用预定义兼容关系、锚点和白名单，不做任意物理模拟。每个核心谜题建议一个主解法和一个替代解法；多解必须带来不同体验，不为数量凑解法。

### 首个谜题：《断裂的书谷》

两本巨大的书形成峡谷，玩家在近侧书本上，远处能看见铅笔盒小镇入口，两端各有一个尺子支点。

主解法：观察尺子和支点 → 进入整理模式 → 尺子吸附到合法锚点 → 预览合法/非法 → 确认落位 → 完整桥体显示 → 玩家实际通过。

替代解法候选：回形针与绳索连接两个锚点。若编辑器不能稳定支持绳索碰撞和角色通行，降级为固定绳索捷径或展示性路线，不阻塞主切片。

成功反馈：小镇入口一盏灯亮起；居民走到桥头或开始使用道路（简单预设行为即可）；地图更新“第一条道路”；日志记录物件用途。

失败恢复：无效摆放显示红色轮廓和简短原因；支持撤销/重置；不消耗资源、不惩罚、不产生软锁。

## 6. 世界地图与区域职责

首版是一张连续桌面世界，不是四张独立关卡；采用“中心安全区 + 多条可回访路线 + 远景地标”。未解锁区域先可见，不必立即可达。

- **铅笔盒小镇：** 温暖、安全、有人生活；深青绿色铅笔盒外壳/拉链、布棚小店、暖窗灯、探险工作间。首版只做 2–3 个固定行为居民，不做复杂日程 AI。
- **书谷：** 好奇、尺度震撼、轻微危险但安全可控；两本巨书、书脊、页边、封面布料、纸张纤维、尺子桥。
- **文具荒野：** 后续开放，不做完整内容。
- **杯岸港口：** 后续开放；首版只做远景预示，不做真实水体物理。

## 7. 美术圣经

风格：**暖金手工微缩童话（Warm Handcrafted Miniature Fantasy）**。真实日常物件的可信材质 + 手工微缩建筑的亲和轮廓 + 温暖电影感光照 + 克制的童话色彩。

不是低多边形玩具风、照片级写实或高饱和幼儿卡通。玩家应觉得这些东西来自一张真实书桌，但被微缩文明重新利用。

核心色彩：
- 暖纸白 #E8D9BF
- 蜂蜜木 #A87345
- 台灯琥珀 #E6A84F
- 深青绿 #315C59
- 夜窗蓝 #263A52
- 旧酒红 #874D4D
- 植物灰绿 #7B8C68
- 黄铜 #B68A4D

视觉原则：远景有尺度反差；中景路线清楚；近景核心资产可观察。木头有方向性纹理和轻微边缘磨损；纸张有纤维和厚度；布料近景可见织纹；陶瓷釉面柔和反光；黄铜只作小面积点缀。细节优先级：轮廓 > 材质大关系 > 主要纹理 > 微小瑕疵。

## 8. 音频与授权

首个切片需要一首经试听的探索音乐、一组小镇环境声、一组书谷环境声、3–5 个关键交互音效和一个成功反馈短句。

候选清单包含 Sunset Plains、Magic Town、Meadow Thoughts、First Light Particles、Goodbye to Friends、Best Friends Theme。源档案的 CC0 是初筛记录，不代表已试听或正式采用；必须保存具体资源页、许可证和原始文件。未试听、未核验许可的素材不得标记为正式采用。

## 9. 新版造世界 AI 编辑器适配（实施口径）

以下是根据当前项目实测技术约束所作的适配：
1. 当前玩家是脚本驱动的运动学控制，普通场景 Collider 不能可靠充当阻挡玩家的实体墙。不得用“撞墙”作为唯一门禁。
2. 保留“玩家整理/改造尺子并改变路线”的体验意图。优先尝试编辑器 GUI 支持的拖动与锚点吸附；若不支持，降级为明确的交互点 + 预设锚点吸附/状态切换；最后才是显式确认按钮。不能出生自动解锁。
3. REST 与完整桥体必须互斥显示；桥体可以是一个 GLB root（内部多个 mesh）或多个子节点，不强制拆成六个独立坡道段。
4. 门禁使用已验证的 Trigger/Lua 状态逻辑和安全返回；激活后仍必须验证玩家能否连续通过桥面到达小镇。
5. 若桥面无法真实承载玩家，先报告最小复现和降级方案，交总设计师批准；不得用 Teleport 截图冒充连续通行。
6. 原始 Web/Three.js 原型仅作为玩法和状态机参考，不是造世界编辑器原生工程。R16 的 47/47 Node smoke test 不执行 WebGL draw，不能证明目标编辑器运行成功。

## 10. 本轮明确不做

不做完整四区、自由物理建造、多人同步、复杂 NPC AI、战斗、生存、海量装饰、复杂剧情演出、真实水体物理和完整基地经营。先证明一个角落的品质和玩法。
