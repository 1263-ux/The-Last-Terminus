# TASK ACCEPTANCE｜资产复用与 A/B/C 当前阶段 Gate

## 0. 证据状态

统一使用：
- PASS：目标编辑器/真实玩家/真人操作按要求通过。
- FAIL：真实复测失败。
- NOT TESTED：没有执行。
- INCONCLUSIVE：执行过但证据不足。
- WAIVED：总设计师书面豁免。

Blender 独立评审 ACCEPTED 不等于造世界编辑器导入 PASS。Agent 自评不等于总设计师 Gate。

## 1. A｜公共技术与集成

| ID | 验收项 | PASS 标准 |

| A-01 | C4 状态脚本 | 支持一个完整 GLB 根节点，或明确配置的多个子节点；参数包含 REST、Bridge/RAMP root 或节点列表、交互区、门禁区、返回点和 yaw |

## 2. B｜书桌站资产导入与可玩闭环

### B-01 资产包接收与登记
- [ ] B 收到 BelowTheDesk-造世界编辑器资产交接包-v1.0.zip。
- [ ] ZIP 完整性通过；7 个 GLB 的 SHA-256 与 ASSET-IMPORT-MANIFEST.md 一致。
- [ ] 保留原始 GLB，不直接覆盖。
- [ ] 将确认采用的 GLB 和清单提交到 shared-assets/desk-world/below-the-desk-kit-v1/；若仓库容量/政策不允许，先报告并使用总设计师交付的 ZIP，不得静默跳过。

### B-02 目标编辑器导入烟雾测试
优先顺序：
1. town-row-v02.glb（无贴图，验证多部件层级和约 24m 尺寸）
2. shopfront-v02.glb（无贴图，验证单体模块）
3. desk-lamp-v01.glb（候选资产，验证模型和摆位）
4. ruler-bridge-full-v01.glb（核心资产，重点验证嵌入 PNG 刻度）
5. cup-harbor-v03.glb（可选远景；纹理解码未验证）
6. ground-paper-v01.glb（底板参考，不代表碰撞面）
7. case3-assembly-reference-v02.glb（仅组合参考，不直接替换最终关卡）

每个采用资产必须验证 SHA、导入后层级/mesh 数、单位/比例/朝向/原点、X 镜像、材质/嵌入贴图、玩家相机可见、保存重开和目标运行时稳定性。

### B-03 玩家相机与摆位
- 当前 B 相机基线仅适用于未改相机的工程：camY≈79.587、camZ≈85.3、pitch≈18° 向下、FOV≈45°。
- 可见性预算：topY <= 79.587 + (z - 85.3) * 0.0787，额外留余量。
- 如果出生点、相机或 FOV 改动，必须重新实测。
- 不得只用编辑器自由视角或节点定向截图验收。
- town-row 约 24m，先原尺寸导入测量，再决定是否缩放或拆分；记录源尺寸与最终比例。

### B-04 尺子桥状态切换
当前资产有两种合理结构：单个 GLB root（内部含多个 mesh children），或导入器拆成多个独立节点。验收按**完整桥体**而不是固定节点数量：
- 激活前：REST 尺子可见，完整桥体隐藏。
- 玩家主动交互后：REST 隐藏，完整桥体所有组成部分出现。
- 刻度、数字、支架、金属箍均显示正确。
- 不能只显示桥体的一部分，也不能出现 mesh 遗漏。
- 若 PNG 刻度纹理不解码，标 FAIL 并排查贴图容器/材质路径；不得用纯色占位冒充原资产通过。

### B-05 核心玩法闭环
一镜到底真实玩家运行，建议 45–90 秒：
1. 正常出生，看到书谷、静止尺子和小镇目标。
2. 玩家理解尺子与通路有关。
3. 玩家主动触发交互，不是出生自动触发。
4. 玩家相机内看到 REST → 完整桥体状态切换。
5. 玩家沿新路线连续走过桥/坡道。
6. 到达铅笔盒小镇，出现至少一个反馈（暖窗、入口灯、声音或场景状态）。
7. 返回/失败恢复有效。
8. 保存、关闭、重新打开后再走一次。

当前玩家是运动学控制，普通 Collider 不能被当成物理墙。门禁用规则/Trigger/Teleport 设计，但桥面是否能承载玩家、玩家是否能实际走到对岸必须真实运行测试。

### B-06 完整垂直切片（5–8 分钟目标）
GDD v0.2 和 VERTICAL_SLICE_SPEC v0.2 将首个垂直切片目标定为约 5–8 分钟。由至少一名未参与设计者完整试玩并记录实际用时。

完整流程至少包含：
1. 入口与尺度建立：看见书谷、尺子、小镇目标。
2. 自主探索：玩家能在近侧平台观察书本、支点和至少一个环境细节。
3. 规则发现：理解尺子与通路的关系，不靠口头讲解。
4. 整理/摆放：完成主动交互、合法预览/确认或经批准的锚点吸附降级。
5. 实际通行：连续通过完整桥体。
6. 世界回应：小镇灯光/入口状态/居民预设动作至少一项变化。
7. 知识或地图记录：记录“第一条道路”或尺子用途；若 UI 不支持，使用明确的环境状态反馈并提交降级说明。
8. 返回/收束：玩家能回安全点或列车，不软锁。

不得用重复刷取、长时间等待或空走填满 5–8 分钟。若实测时长偏离目标，提交时间分布、卡点和具体原因，不要伪造时长。

### B-07 失败恢复与存档
- 无效摆放可撤销/重置，不消耗资源。
- 未解锁误入门禁区能回安全点并继续。
- 关闭重开后场景、桥状态、脚本绑定和已完成谜题状态符合设计。
- 至少完成一次重开后的完整主流程。

- [ ] 核心资产导入矩阵中的尺子桥和小镇方案 PASS。
- [ ] 玩家视角看见 REST、完整桥体和小镇。
- [ ] 玩家主动交互，非自动触发。
- [ ] 完整桥体切换，无 mesh 遗漏。
- [ ] 一镜到底连续通行到小镇。
- [ ] 到达反馈、失败恢复和重开验证通过。
- [ ] 完整垂直切片由未参与设计者完成，记录实际用时；目标 5–8 分钟，偏差有证据和解释。
